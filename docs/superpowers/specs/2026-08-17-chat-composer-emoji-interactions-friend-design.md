# 畅聊聊天输入、表情、消息交互与好友页设计规格

**状态：** 已批准  
**日期：** 2026-08-17  
**基准：** iPhone 15，393 × 852 CSS/Figma px  
**设计源：** Figma `zpzwTbnj1hqx80tyRygX78`，页面 `00 Cover`；相关节点 `36:1287`、`36:1356`、`36:1425`、`36:1494`、`35:63`、`35:382`

## 1. 范围与硬性边界

本规格覆盖“20 Messages & Chat”聊天输入区、表情面板、消息长按菜单、提醒、拍一拍、@ 提及，以及“40 Contacts & Friend”的好友资料和好友设置。所有用户可见品牌名继续使用“畅聊”。

- Matrix 负责端到端加密消息、附件、表情仓库事件、撤回和设备间同步。
- 业务 API 继续负责身份、账本、钱包和红包；聊天 UI 不从 Matrix 消息推导或修改金融状态。
- 服务器不得获得恢复密钥、房间密钥、消息明文、附件明文或解密后的通话媒体。
- “删除”只隐藏当前设备本地记录；“撤回”才发送 Matrix Redaction，并从所有设备撤回。
- “添加到表情”只在图片和 GIF 消息上显示。

## 2. 聊天输入区

### 2.1 固定 DOM/Widget 顺序

底部输入栏必须保持以下语义顺序，不允许由页面临时重排：

```text
ChatComposerBar
├─ ComposerVoiceButton
├─ ComposerInputSurface
│  └─ EditableText | HoldToTalkButton
├─ ComposerEmojiButton
└─ ComposerTrailingButton (More | Send)
```

Flutter key 固定为：`chat-composer`、`composer-voice`、`composer-input`、`composer-emoji`、`composer-more`、`composer-send`。触控目标不得小于 44 × 44 px；输入区视觉高度 40 px，整栏最小高度 56 px，左右间距 8 px。

### 2.2 状态机

| 状态 | 中部 | 右末端 | 下方面板 |
|---|---|---|---|
| idle | 文本输入框 | 更多 | 无 |
| focused-empty | 文本输入框 + 系统键盘 | 更多 | 无 |
| focused-has-text | 文本输入框 + 系统键盘 | 发送 | 无 |
| voice | 按住说话 | 更多 | 无 |
| emoji | 文本输入框 | 更多或发送 | 表情面板 |
| more | 文本输入框 | 更多 | 更多功能面板 |

语音、系统键盘、表情面板和更多面板互斥。切换到面板时保留未发送文本与光标；发送后清空文本但不破坏回复上下文。

### 2.3 更多面板

“更多”面板以 4 列网格收纳图片、拍摄、语音通话、视频通话、红包和文件；使用真实矢量图标，不使用字符或占位方块。红包发送仍通过业务 API 创建，再由 Matrix 发送不具权威性的展示事件。

## 3. 表情系统与私有同步仓库

### 3.1 面板

采用维护中的开源 emoji 数据/选择器库，不在业务代码硬编码少量 Unicode 列表。面板固定包含：

- 最近使用：本地即时更新，并在账号设备间合并同步。
- 全部表情：按标准分类浏览和搜索，支持肤色变体。
- 我的表情：静态图片与动态 GIF；GIF 必须保持动画播放。

从图片/GIF 消息的长按菜单选择“添加到表情”后，应去重、加密上传并加入“我的表情”。其他消息类型不得出现该入口。

### 3.2 Matrix 私有加密表情仓库

每个账号使用一个仅自己的加密 Matrix 房间作为私有仓库。房间 ID 可记录在账号数据中；图片/GIF 二进制使用 Matrix 加密媒体上传，元数据作为该房间的加密事件发送。事件类型命名空间为 `com.changliao.emoji.*`，至少包含新增、删除和最近使用合并事件。

去重键使用明文文件在设备端计算的 SHA-256；服务器只接收加密媒体和密文事件。冲突采用事件时间与稳定 ID 合并，不以某一设备快照覆盖整个仓库。

## 4. 消息操作

### 4.1 长按菜单能力矩阵

基础操作为转发、删除、多选、引用、提醒；图片/GIF 追加“添加到表情”；自己发送且服务器时间不超过 2 分钟的消息追加“撤回”。系统消息、通话状态和红包等受限类型只显示其允许的安全子集。

- 转发：目标房间重新加密发送，不转发密钥或原始密文；红包和系统控制事件不可转发。
- 删除：把事件 ID 写入当前设备的本地隐藏集合，不发送 Matrix 事件，不影响对方或其他设备。
- 多选：进入批量模式，支持批量转发和本地删除。
- 引用：发送 `m.in_reply_to` 关系，输入区显示可取消的回复预览。
- 撤回：校验发送者和 `origin_server_ts` 的两分钟窗口后调用 Matrix Redaction；客户端时钟不能扩大窗口。

### 4.2 提醒

用户长按消息选择“提醒”后必须选择具体时间。提醒定义作为加密事件同步至账号私有控制房间；每台已同步该提醒的设备建立本地通知计划。通知正文默认使用通用文案，不把消息明文写入推送载荷。取消和完成状态同样通过加密事件合并；设备离线期间的到期提醒在下次同步时标记并提示。

### 4.3 拍一拍与 @

- 双击头像发送 `com.changliao.nudge` 加密房间事件，并在时间线显示“你拍了拍…”系统气泡。
- 拍一拍后缀可自定义，并通过账号私有加密配置同步；事件保存发送时的显示快照，避免历史文案漂移。
- 长按头像向输入框插入 `@显示名`，同时维护 Matrix 用户 ID；发送时写入 `m.mentions.user_ids`，不能只发送不可解析的纯文本。

## 5. 好友资料与好友设置

严格映射 Figma，而不是按近似风格重绘。

### 5.1 好友资料（`35:63`）

- 顶部：返回、居中标题“好友资料”、右侧更多。
- 主卡：头像、昵称、畅聊号及必要身份信息，间距与分割线遵循 Figma。
- 朋友圈预览：缩略图行和进入箭头。
- 底部主操作：发消息、语音通话、视频通话，使用真实图标和 44 px 以上触控区。

### 5.2 好友设置（`35:382`）

顶部为返回和“好友设置”。列表顺序固定为：备注、标签、朋友圈权限、黑名单、删除好友。删除使用危险色但仍需二次确认；黑名单为可访问的开关控件。任何业务暂未接通的入口也必须呈现明确禁用/失败状态，不允许无响应占位。

## 6. 视觉与主题

- 浅色版为全部状态的完整设计；深色版由统一 Token 自动切换，并在消息、聊天和好友关键页提供代表画板。
- 底部面板、菜单和弹窗使用同一圆角、分隔、遮罩和动效 Token。
- 所有图标来自统一图标组件或 SVG 资产，禁止 emoji 字符充当功能图标。
- 动态表情遵循系统“减少动态效果”设置：关闭自动循环或显示静态首帧。

## 7. Figma 交付规则

在现有文件内新增命名清晰的独立 393 × 852 Frame，不新建重复页面。至少展开：默认输入、键盘/发送、更多面板、最近表情、全部表情、我的表情、消息菜单、多选、提醒选择、撤回边界、拍一拍/@、好友资料、好友设置。原有参考画板保留，新增画板标记为本规格更新版。

## 8. 验收标准

- Widget 测试覆盖输入状态机、44 px 触控区、菜单能力矩阵、仅图片/GIF可添加表情、两分钟撤回边界、本地删除不发送 Matrix 事件、@ mentions 数据。
- 单元/集成测试覆盖表情加密仓库合并、提醒多设备同步、GIF 动画呈现、Redaction 调用和好友页导航。
- 浅色/深色 Golden 覆盖关键状态；393 × 852 无溢出，系统键盘出现时输入栏可见。
- `flutter analyze`、目标测试与仓库 `scripts/verify.ps1` 全部通过；验证证据写入 `docs/verification/`。
