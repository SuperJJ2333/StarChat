# 后台导航、分页及客服权限设计

授权：用户于 2026-09-30 明确要求六项变更并授权直接实施。沿用管理员专属提现设计。

1. 钱包在侧栏展开为链上流水、人工出款、监控与事故、所有者转出、账户安全五个独立路由。只挂载所选模块，所有路由仍经过钱包访问验证。
2. 后台业务列表默认每页 10 条，可选 20/50；更改页大小重置游标和页码，失败不把旧数据当新页。嵌入式详情事件时间线不属于独立分页列表。
3. 客服、财务客服、客服主管显示中文徽章；管理员逐个撤销角色，保留其他角色、审计和幂等性。
4. 用户与 IP 的解除封禁依据服务端有效封禁记录及其 ID，调用既有撤销接口，不根据展示状态猜测 ID。
5. 客服获得封禁管理、注册统计、广告、公告和点钻流水权限；点钻流水为查询，不能借此发放点钻、操作提现或管理客服角色。
6. 所有新增权限按当前角色和已开通管理会话验证，角色撤销立即生效。保留写入审计、Outbox 与幂等键。

验收：独立导航/直接链接、各列表 10/20/50、中文徽章/逐角色撤销、用户与 IP 解除封禁、客服五模块正向及财务/角色管理反向鉴权、生产资源与 API 证据。
