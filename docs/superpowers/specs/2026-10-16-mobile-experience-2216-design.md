# 2215体验优化批准规格

授权：2026-10-16用户接受同会话五问题方案并要求开始实施，允许模拟器Debug安装。按已批准推荐方案执行，不再重复设计审批。正式渠道现为Android/iOS0.4.46+2215；此次使用新候选0.4.47+2216，需构建前复核占用。

1. 冷启动：先保留安全身份/安装连续性/密钥检查，缓存就绪时展示真实本地会话，避免非必要串行准备；可安全滚动预览，身份未完成时不开放发送/金融/跨账号访问。锁定/迁移失败清晰降级且不清库。
2. 房间：最近40条优先，最大200UI模型；保持首屏已有内容，后台历史与可选元数据不阻塞；空白改有语义占位，保持事件ID+视口偏移，取消退休任务。
3. 媒体：已有小图先绘制，超级表情默认静态可点击播放，资源等待不空白；GIF静态首帧缓存、同账号重进复用、有界预加载与内存回收。闪照不走普通磁盘缓存。
4. 发送：复用GalleryPhoto.thumbnail/poster，稳定txid立即创建带预览气泡；后台准备上传ACK，状态阶段明确；持久任务重启后在消息流恢复，完成后不闪白/重复；替代待发附件栏，仍提供失败重试取消，不丢任务。云端无本地预览可显示明确非空媒体卡片。
5. 权限：初始化不主动申请通知，按需协调系统申请；旧prompted标记不能封死未决定用户；分辨通知status及alert/sound/badge，拒绝引导设置，不强制反复请求。麦克风/摄像头按功能独立申请。生产APNs身份复核，匹配凭据/真实iPhone缺失只阻断相应验收。

目标是改进，不把静态分析或Debug测量冒称正式真机SLO。建议目标沿用会话方案：缓存冷启动列表P95≤1.5s/可交互1.8s、最近40条500ms/重进150ms、缓存预览100/300ms、已有发送小图100ms/9图300ms、权限返回状态1s；首次安装/迁移/无本地iCloud资源分开统计。

保持E2EE、账号代际、租约取消、outbox幂等、撤回/闪照边界。缓存派生数据兼容新增；不可清空原始库或更换签名。HTML demo+registry保持功能与状态一致。系统约束遵守既有skills/AGENTS，安全敏感认证变更需要ADR；本轮尽量在既有授权范围优化顺序和UI，不提前认证。
