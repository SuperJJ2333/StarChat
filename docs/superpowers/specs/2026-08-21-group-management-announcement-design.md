# 群聊管理、公告与导航栏设计

**状态：** 已批准  
**日期：** 2026-08-21  
**范围：** Flutter Matrix 群聊界面

## 目标

以微信式列表、开关、二次确认和成员管理交互补齐群聊管理能力；所有页面导航栏固定使用 `#F7F7F7`。群设置、角色和公告元数据保存在 Matrix 房间账户数据中；成员资格变更仍通过 Matrix 房间 API 生效。

## 数据模型与权限

`com.liuhetong.group_chat.settings.v1` 增加版本化字段：`owner_id`、`admin_ids`（最多3个）、`qr_join_enabled`、`join_approval_required`、`only_managers_can_rename`、`announcement_version`、`announcement_read_version_by_user`。房间创建者或 `owner_id` 是群主；管理员由 `admin_ids` 判定。群主可管理管理员、转让和解散；管理员可管理公告、二维码、入群确认、改名限制和移除普通成员；普通成员只读。

群二维码使用仅含 room ID 的 Matrix URI 展示。扫码入群仍必须由服务端成员资格和房间权限确认；开启进群确认时客户端呈现待审核状态而不伪造已加入。

## 页面和交互

- 所有 `CupertinoNavigationBar` 强制不透明 `#F7F7F7`，关闭滚动透明与背景模糊。
- 聊天信息页：右上搜索；成员网格恒有加号，群主/管理员多减号；新增群二维码、群管理入口。
- 成员搜索/移除页：群主、管理员、其余成员按显示名排序；顶部搜索；移除多选与二次确认。
- 群管理：开关立即写入账户数据；管理员上限3；转让与解散采用二次确认。
- RoomPage：未读公告存在时，在导航栏下呈现40dp公告条；打开公告时写入当前版本的已读状态；仅群主/管理员显示编辑入口。
