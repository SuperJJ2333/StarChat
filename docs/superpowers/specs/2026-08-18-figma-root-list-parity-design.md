# Figma 根列表与通讯录索引严格映射规格

**状态：** 已批准  
**日期：** 2026-08-18  
**批准依据：** 用户明确选择“A．原始节点严格映射”，并在本轮确认颜色、头像和通讯录索引要求。

## 1. 权威设计源

- 消息首页：Figma `20 Messages & Chat` 原始节点 `31:80`。
- 通讯录：首页原始节点 `34:80`（`contacts-index-default`）。
- 发现：首页原始节点 `29:2726`（`discovery-home-default`）。
- 代码不得使用“近似微信风格”、Cupertino 默认色或审查画廊新增节点替代上述原始节点。

## 2. 颜色硬约束

- 浅色页面背景：`#EDEDED`。
- 浅色顶部状态栏、页面导航栏和底部主导航：`#F7F7F7`。
- 消息会话行、通讯录入口行、联系人行和发现入口行：`#FFFFFF`。
- 深色模式继续通过同一语义 Token 自动切换；不得把浅色字面量散落在页面代码中。

## 3. 头像硬约束

- 消息会话与通讯录头像统一为圆角矩形，不得使用圆形裁剪。
- 头像图片、网络错误占位和文字占位必须共享同一裁剪边界。

## 4. 通讯录分组与索引

- 右侧索引顺序固定为 `★, A-Z, #`；`★` 为星标好友入口，`#` 为无法归入 A-Z 的联系人。
- 联系人先按星标、再按 A-Z、最后按 `#` 分组；组内按稳定的、不区分大小写的排序键排序。
- 中文显示名使用可用的拉丁用户名首字母作为稳定分组后备；无法获得 A-Z 首字母时进入 `#`。
- 点击右侧索引应滚动到已有分组；无联系人分组仍保留索引入口，但不产生空白分组标题。
- 星标状态来自联系人 `starred` 字段；为兼容既有服务，也识别 `starred`、`星标好友` 标签。

## 5. DOM / Widget 映射约束

- `CupertinoPageScaffold > CupertinoNavigationBar + SafeArea > list surface` 层级不得被私有覆盖样式绕开。
- 共享列表行必须使用 `surface/elevated`，禁止读取 `barBackgroundColor`。
- 导航栏只使用 `surface/primary`，禁止读取 `scaffoldBackgroundColor`。
- 颜色、圆角、索引顺序必须由可测试的公开 Token 或组件常量表达。

## 6. 防回归证据

- Widget 测试断言导航、会话行、通用列表行的精确颜色和头像裁剪形状。
- 通讯录测试断言完整索引顺序、星标/A-Z/# 分组顺序以及 393×852 下无 overflow。
- 最终验证包含 Flutter focused tests、全量测试、analyze、仓库 verify、APK 构建与模拟器安装。
