验收：

3. 收到图片/GIF/视频后无需打开会话即可提前下载，朋友圈无需进入页面即可缓存。覆盖后台/锁屏；Android 使用既有前台保活/系统下载机制，iOS 必须尊重系统调度，不能承诺被强制终止后持续执行 Dart。所有可见 GIF 同时播放，离屏/后台暂停动画；重入会话直接使用已有缩略图。缓存、队列和迟到回调按账号隔离，退出登录取消，闪照不预下载、不留存；E2EE 密钥/明文不得发到服务端。
4. 排查其余网络/性能热点，实施有证据且与本次负载相关的优化，保护发送幂等、已读、历史搜索及安全边界。
