# 畅聊 10 Auth Figma 与 Flutter 修复设计

**日期：** 2026-08-16  
**状态：** 已批准  
**设计基准：** iPhone 15，393×852 CSS/Figma px  
**Figma 文件：** `zpzwTbnj1hqx80tyRygX78`，仅更新原 `10 Auth` 页面

## 1. 目标

修复认证页残留的旧产品视觉，使 Figma `10 Auth` 与 Flutter 登录、注册、邮箱验证页面统一使用“畅聊”品牌、用户提供的新背景和指定 SVG Logo。登录页增加协议确认与轻量注册入口，注册流程本身不受协议状态约束。

## 2. 已批准的视觉方案

采用 **A · 顺序式承诺**。登录卡片自上而下固定为：

1. `assets/branding/liuhetong_logo.svg`
2. 标题“畅聊”
3. 说明“使用用户名或邮箱登录”
4. 用户名/邮箱输入框
5. 密码输入框
6. “端到端加密 · 恢复密钥仅保存在设备”
7. “我已同意《用户协议》和《隐私政策》”
8. 登录按钮
9. “还没有账号？立刻注册”

认证页背景统一使用用户提供的 `assets/landing.png`。Logo 不再使用文字方块或 `launch_logo.svg`；所有认证页通过同一个 `AuthBrandMark` 渲染指定 SVG。

## 3. 组件与交互规则

### 3.1 `AuthBrandMark`

- 唯一资产源为 `assets/branding/liuhetong_logo.svg`。
- 固定语义标签为“畅聊 Logo”。
- 通过 `flutter_svg` 渲染，保持原始宽高比，不创建替代字形或内联 SVG。
- 登录、注册、邮箱验证不得自行重复实现 Logo。

### 3.2 登录协议

- 协议状态只存在于登录页本地状态，不写入业务 API、Matrix 或持久化存储。
- 初始状态未勾选；登录按钮禁用。
- 勾选后，登录按钮在非加载状态下可用。
- 加载时输入、复选框、协议链接和注册入口全部不可交互。
- 用户名或密码为空时继续使用现有错误“请输入用户名和密码”。
- 《用户协议》和《隐私政策》使用品牌绿色链接视觉，并分别暴露可选回调入口；本阶段不伪造协议正文或外部 URL。

### 3.3 注册入口

- 登录页移除“注册账号”次级大按钮。
- 当 `onRegister` 存在时显示单行“还没有账号？立刻注册”。
- 只有“立刻注册”为可点击的品牌绿色链接，调用现有 `onRegister`。
- 加载期间不可点击。

### 3.4 注册和邮箱验证

- 注册页继续由邀请码和现有字段校验控制提交，不增加协议勾选。
- 注册页和邮箱验证页统一使用共享 Logo 与新背景。
- 现有注册、验证控制器和 Business API 数据流保持不变。

## 4. Figma `10 Auth` 状态

在原页面内更新并展开独立 393px Frame，不新增 `09 登录与注册` 页面：

### 浅色

- 登录／已勾选

- 登录／字段错误
- 登录／服务异常
- 注册／默认
- 注册／填写
- 注册／加载
- 注册／字段错误
- 邮箱验证／默认
- 邮箱验证／倒计时
- 邮箱验证／成功
- 邮箱验证／失败

### 深色关键代表状态

- 登录／已勾选

所有 Frame 使用现有 Token、393px 固定宽度和自然内容高度；背景、卡片、字段、复选框、按钮和文字链接保持严格 DOM/组件槽位对应。

## 5. Flutter 结构

- `ImmersiveAuthScaffold` 继续唯一负责 `landing.png` 背景和安全区。
- `AuthSurfaceCard` 继续负责表单卡片。
- `AuthBrandMark` 只负责统一 SVG Logo。
- 新增小型 `AuthAgreementRow`，固定包含复选框、两项协议链接和禁用状态。
- 新增小型 `AuthInlineRegisterLink`，固定包含提示文字与注册动作。
- `LoginPage` 组合上述组件并拥有协议勾选状态。
- `RegistrationPage`、`VerificationPage` 复用品牌组件，不引入协议状态。

不改变认证控制器、API 合同、Matrix 身份绑定、会话存储或安全边界。

## 6. 可访问性与异常状态

- 复选框触控目标不小于 44×44px，并公开 checked/enabled 语义。
- 协议链接和注册入口具有独立语义按钮与明确中文标签。
- 禁用和加载状态不仅依赖颜色表达。
- 错误信息继续使用 live region。
- 393×852 为基准，小屏幕与键盘弹出时表单保持可滚动，背景不随键盘位移。
- 深色模式保持文本、边界和品牌色对比度。
