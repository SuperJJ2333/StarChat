# 网络交付首批设计

授权：用户在网络现场评估后明确优先推进媒体分流、区域TURN、主区多可用区及大陆真实线路测试。复用前轮架构选择，不重复请求方向审批。峰值1000在线、大陆/东南亚各半；视频并发与东南亚国家未知。

本批交付可验证的上线准备件：公开静态媒体S3/CloudFront基础设施、两AZ网络/ALB基础设施、区域TURN部署配置生成器、真实测点运行的HTTPS采样工具及独立发布手册。没有AWS身份/预算/真实测点时不伪造部署或测量。CloudFormation不创建无人维护的空应用镜像，网络基础设施不冒称实现Synapse/数据库HA。

媒体先覆盖公开版本化安装包和静态文件；私有S3仅允许OAC访问，TLS访问，版本保留。此公开分发stack禁止聊天附件，私密媒体授权、MXC生命周期仍需后续协议设计。CDN部署采用AWS分配域名试点，不改现有DNS或更新发布设置。

基础网络两个不同AZ、公有ALB子网、私有应用/数据子网，私有子网不自动发公网IP。ALB HTTPS凭用户实际区域ACM证书，后端只受ALB安全组允许；不自动创建NAT费用、RDS、Synapse节点或GA。需写明出网方式、同区域PG/Redis、主角色单写与故障演练缺口。资源保留策略/回滚边界明确。

TURN每区域独立公网IPv4和DNS-only域名，沿用coturn4.6.3-r3、长期凭据REST共享secret；TLS443、UDP/TCP3478，relay范围扩大并明确网络安全组。采用host network避免大范围Docker port映射；密钥只从运行环境读取，生成受限文件不输出凭据。证书使用显式路径，校验FQDN/IP/端口范围/secret强度及配置注入。关闭管理CLI、loopback/link-local/private peer以减少滥用；多节点ICE列表/证书更新/真实allocation验证在手册说明，不能靠TCP端口开放宣布通话成功。现有生产turn列表暂不改。

线路采样器在用户控制的真实测点运行curl，HTTPS证书校验、无账户/消息载荷、不发送鉴权、有限次数/超时/串行流量；采集DNS/TCP/TLS/TTFB/total/status/remoteIP，保留失败分母，按成功样本计算分位数并明确样本量。标注用户声明的城市/运营商/网络与UTC时间，不把自报标签当运营商证明、不把本机fake-IP路径当真实大陆线路。拒绝含凭据或query的URL及非HTTPS；仅探测明确给定公开目标，不做端口扫描。输出仅本任务证据目录。工具不自动购买探针、不把HTTP探测当TURN/端到端聊天测试。

评审顺序：规格再质量安全。上线顺序：真实测点基线→公开CDN对照→区域TURN真实通话→多AZ应用与数据迁移；每阶段有验收和回退，尚未具备条件者明确标记。
