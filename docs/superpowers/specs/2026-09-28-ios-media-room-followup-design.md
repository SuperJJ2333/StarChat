# 朋友圈媒体、房间通知与历史检索修复设计

日期：2026-09-28。状态：已完成只读调查，新增行为方案待确认；尚未实现或构建。

## 目标与交付边界

覆盖用户本次九项要求。源基线为 Android 0.4.19/2188 已交付的 f433381a14d4549b25001059870857d1bfe57a42，保留此前登录、系统锁屏、全链路性能、请求错误细类及启动诊断。公开 iOS 仍为 0.4.7/2173；不能将后来的共享源码修复视为已进入旧 iOS 包。用户尚未说明本次各现象实际发生的平台/build。

最终交付新的 iOS IPA **待企业重签候选**。用户完成企业签名、回传并确认版本/build、Bundle ID、大小及签名身份后，才进入分发交接。本轮不触发 TestFlight 上传、Android 发布或改最低支持版本。若需要新增朋友圈封面服务，完成候选与独立审查后再单独确认服务发布。

## M01：离开发表页后继续上传

根因：moment_composer_page 的 saving 状态覆盖媒体上传、发表与草稿清理，busy 阻止返回；上传又依赖 mounted，不能简单取消 await 后退出。

采用账号所属的 MomentPublishCoordinator：点击发表后接纳不可变任务，页面即返回；由应用层依次完成素材准备、上传、发表。任务使用稳定幂等键，正文、可见范围及选取素材在接纳时冻结。上传成功后刷新朋友圈；失败保留任务并提供重试/取消。清理草稿失败不把已发表成功改为失败。

任务和本地素材由应用沙盒持有，避免页面销毁、图库临时文件失效造成丢失。队列及准备并发有界；恢复时仅当前相同账号可执行。会话约束网关在每个请求发起时验证捕获的账号/会话代际，切号、登出立即使旧任务失效；不把旧任务移交新账号，不持久化认证令牌。

后台含义：离开发表页后 App 内继续；系统允许后台执行时继续；iOS 暂停或结束进程后在下次启动/恢复时续作。不能承诺系统杀进程后仍持续传输。采用可恢复队列，比仅内存任务可靠；完整原生后台 URLSession 重构会扩大范围，当前不采用。

## M02：朋友圈与会话相同媒体限制

复用会话 GalleryPhoto 的惰性文件/字节源及公开媒体准备接口。视频允许大原件经既有 H.264/AAC 转码，最终输出实测不超过 20 MiB；仍超限时明确拒绝，不上传。图片/GIF使用会话同样的有效性及最终 20 MiB 上限，保留朋友圈现有静态图片压缩策略。不得为检查体积先把大原件全部加载进内存。

媒体准备和上传接入既有 PerformanceTrace，以固定阶段/结果/耗时记录；不记录正文、文件内容、本地路径、密钥或凭据。

## M03：打开房间立即消除通知与角标

根因：ConversationReadState 只更新本地会话显示；通知协调器没有订阅房间打开/已读变化。角标主要在消息事件、启动或恢复前台刷新，且缺少进入房间时取消对应系统通知的调用。

通过公开的读状态事件接入通知协调器。实际显示房间后清除该房间及其合并保留历史来源的本地通知；iOS 还按远端推送 userInfo 的 room_id 精确匹配已送达通知。只处理对应房间，保留其他房间和通话通知。同步重新聚合角标，沿用服务器计数与本地已读抑制规则，不直接全局置零。

对通知展示与清除、角标异步快照加顺序/代际保护，避免迟到展示重新出现或旧快照覆盖新角标。保持系统未认证锁屏不得操作的既有门槛。

## M04：日期只有有消息/无消息

根因：现有月历只用已加载时间线和两次月首/月末探测，不能确认月中日期；unknown 日期仍可点，随后进入最长 13 秒远端定位。另有 live/context 不连续窗口误合并覆盖跨度的缺陷。

使用当前账号、规范房间及保留历史来源的设备本地消息快照，建立日期集合和本地 anchor。完成读取后日期格只有“本机已有可显示消息”和“没有本机可显示消息”，仅前者可点；点击直接使用本地 anchor。没有完整月快照时采用整月加载/失败状态，不开放单个未确认日期点击，也不把未知记录谎报为空。

此处有/无的范围是本机已保存消息，不宣称包括从未同步到设备的服务器历史。撤回、隐藏、清空、解密更新、账号切换和保留来源变更均使相应投影失效。

## M05：滚动自动加载与旧记录响应

根因：普通列表/媒体网格已有滚动续页，却仍保留“查看更多/继续查找”按钮；空 continuation 或不足一屏会不能滚动。房内搜索已读本地 SQLCipher，稀疏旧命中每新关键词从头 O(N) 投影，不能据此归因网速或物理索引损坏。

去除正常加载按钮；接近底部自动续页，不足一屏及空 continuation 自动有界推进。保留真正失败时的重试。single-flight、查询代际及无进展游标保护防止重复请求、无限循环和迟到覆盖。

复用账号/房间所属的本地投影快照，首次扫描分批 yield，后续关键词及月历复用，消息增量/撤回等正确失效。不使用被裁剪且排除媒体的 GlobalSearchIndex 来判断所有日期。实际无消息以本地穷尽证据为准，不能用过滤后的短页直接当穷尽。以 10k/100k 稀疏旧消息测试记录扫描、投影次数与响应，不预先承诺未测量的真机毫秒数。

## M06：无法解密公告仍可管理

根因：旧密钥失败已有“重新编写”流程，但确认框期间全局同步会递增 loadEpoch，任意无关消息也可能取消操作；失效引用返回 null 转普通 StateError 后不会开放管理流程。

依据实际公告引用、服务身份和当前权限判断确认是否有效，无关同步不取消。明确提供删除公告、重新编写；缺旧密钥不要求先解密旧正文。删除只清除公告引用，新正文继续发送加密事件。遵守 Matrix 实际 state power-level 和加入状态，不自动降低门槛；普通成员不能改写。

对于整个加密客户端未启用的情况，清除公开空引用与发送加密正文分别检查：不得回退明文。若实际实现改变既有 E2EE/权限边界，须补 ADR 及领域/安全审查，不能夹带在 UI 修复中。

## M07：关闭公告栏保持关闭

根因：RoomPage 传实际 _LeaseAnnouncementService，但横幅只为具体 MatrixGroupAnnouncementService 自动推导持久 scope，实际 scope 为 null。

RoomPage 显式传当前账号＋房间的稳定 scope，按公告引用版本保存关闭状态。重进房间、应用重启后相同公告保持隐藏；不同账号不共享；新公告显示。通过真实 lease 接线验证，避免只测试直接服务对象。

## M08：大量媒体转发与选中效果

根因：批量转发只冻结媒体元数据，却将每条完整附件 reservationBytes 作为已持有内存累加，超过 128 MiB 就拒绝；现有 deferred preparation 预算可以在真正准备时有界保留。另消息只显示勾选圆圈，气泡没有持续选中背景。

保持逐附件上限、队列任务数及加密房间/账号门槛；冻结元数据按实际持有成本接纳，下载/解密只在准备阶段申请原有字节预算，维持有限并发与结果复用。对于批量目标扇出超过待执行窗口的情况，使用有界分批调度及稳定事务 ID，已成功项目不重复发送；不得简单放大内存上限或取消限流。

选中的消息行/气泡持续显示共享引用定位高亮色，取消选择恢复；保留勾选和无障碍选中状态，点击行可切换选择。引用跳转仍使用短暂脉冲，不改变选择本身的持续显示。

## M09：跨设备朋友圈视频封面

根因：MomentVideoTile 只查当前账号本地 poster，上传者本机之外没有封面；现有 DTO 只有视频 URL/cache key，没有远端小封面。

推荐新增独立小封面媒体引用：视频准备时本机生成有界小封面，经既有媒体上传/可见范围校验发布。服务扩展为可选字段，旧客户端和历史动态兼容；不把 Matrix 明文附件或密钥带入业务域。新客户端优先远端小封面，已有本地视频可异步抽帧兜底，账号/媒体单飞与失效保护保持。

替代方案是不改服务：可见 tile 下载完整视频再抽帧，首次可能每条消耗最多 20 MiB；优点是无需服务部署，缺点是封面慢且耗流量。已向用户提交此取舍，等待选择；不能静默把本地探测函数变为完整下载。

## 测试与 IPA 构建

每项先证明失败再实现，覆盖退出/重试/切号、媒体超限、通知展示清除竞态、日历与续页边界、管理员失权及新版公告显示、批量转发内存上限和幂等。

冻结最终候选后按影响范围执行共享 Flutter 门禁与原生推送/锁屏验证；先规格符合性再质量/安全审查。Windows 无 Xcode。使用已存在的 GitHub macOS 构建能力，独立 codex 候选分支触发仅构建流程，不覆盖远端更新后的 workflow，不运行 TestFlight 上传。实际工具/依赖/源 hash、run ID、退出码及未执行项如实记录。

现有纯 macOS Swift Package 门禁把含 UIKit 的整个 RunnerTests.swift 复制进去，且漏 IOSMessageNavigationGate；新候选必须分开纯 Foundation/Security 核心测试和 iOS 原生测试，不能把缺类型/缺 UIKit 当通过。构建显式启用 CHATFLOW_PERFORMANCE_METRICS=true；候选工作流当前未传该 define，不能以 Debug 默认开启代替正式 IPA 的监控启用。最终 IPA 校验版本、Bundle ID、SQLCipher、音频/VoIP/APNs、权限声明、代码资产与候选来源，明确仍待企业重签及真机验收。
