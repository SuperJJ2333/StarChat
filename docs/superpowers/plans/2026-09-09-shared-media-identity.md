# 统一媒体输入与用户展示实施计划

授权依据：用户已明确要求执行检查与改造；本计划落实其指定的共享架构，不增加产品选择。

规范：`docs/superpowers/specs/2026-09-09-shared-media-identity.md`。

1. 分别审计会话/朋友圈媒体路径及全局用户展示路径，列出共享点和偏差。只在隔离工作目录修改。
2. 针对评论独立 Emoji 面板、相册入口、GIF 丢失动画及用户展示覆盖问题补充失败测试。
3. 复用会话媒体组件/策略，补齐朋友圈 GIF 接收与实际内容校验；保留业务域上传及权限边界。
4. 在共享数据层统一身份解析与更新，迁移关键页面，测试备注更新、缓存和账号隔离。
5. 执行规格与质量审查，更新组件登记及验证记录，运行相关测试、分析、UI 契约和 scripts/verify.ps1。
6. 真机自动化 harness 只允许独立测试包；不得使用正常应用包名执行 flutter drive，不得卸载或清数据。用户随后明确要求手动检验 Debug 版，已按正常应用包名构建完整 Debug 2075 并用 adb install -r 安装，详见 `docs/verification/2026-09-09-shared-media-redmi-debug.md`。

文件归属：主代理负责本文、规范、后端媒体及其测试和验收记录；媒体/身份审计代理初始只读，实施前另行明确互不重叠的文件归属。
