# 钱包客户端与生产服务整合

依据：用户已要求完善配套 API、迁移、权限并联合验证。沿用已批准 ADR-0013、0014、0056、0057、0058，不重新设计资金或认证策略。

## 基线与范围

正式客户端基线 4912d062（0.3.68/2072）；主目录钱包实现为待导入源。线上只读核对得到 API 11c2c59b95e1、Worker 27bc9f7de31f、数据库 0056_merge_moment_comments。当前 manual_tron / address_only / manual_liquidity 及四项独立开关在 API 和 Worker 一致；不以 legacy real_funds=false 推断全部功能关闭。

责任文件：钱包客户端目录及其测试、BusinessApiClient 的钱包请求账户隔离接口、与线上一致的后端 API/Worker/迁移及契约基线、集成测试、运行手册和验证报告。主目录仅作为只读源，不覆盖其未提交修改。保留正式分支登录、朋友圈、统计助手及头像修复。

## 执行

1. 保存生产非秘密的镜像、schema、策略及源文件摘要；归档差异。先导入客户端回归，验证旧正式客户端缺少新版钱包及账户隔离参数。
2. 按钱包范围导入组件，手动合并公共 API 的钱包会话隔离，保留既有登录退出修复；跑钱包、账户切换和能力开关回归。
3. 同步已部署的后端源码与生产迁移合并图，保留已部署的朋友圈分支。比对 Flutter 调用路径、OpenAPI、认证和幂等要求，补缺口测试；不直接运行旧分支 upgrade head。
4. 在合成隔离数据库验证迁移链、重复升级、旧记录保留和 append-only 约束；验证未登录、普通用户/管理员边界、未知结果同键重试、账户切换以及功能开关的独立语义。
5. 先规格复核再质量/安全复核；执行相关 Flutter 与仓库验证，形成客户端/服务端共同基线和发布前清单。

本轮授权是整合与验证，不代替真实钱包所有者执行真实付款、绑定、资金恢复或开关修改。线上现有钱包已部署，本轮如无新增 schema/API 缺口，不重复部署或迁移。Android 新版发布需先完成这份共同验证；iOS 保持不发布。

## 核对期间的基线更新

生产在本轮期间由其他发布升级为 API `c76be88a7e5b` / 数据库 `0057_merge_direct_room`，Worker 不变。已按快照摘要导入六个私聊预约相关文件，保留最新线上修复。最终共同迁移头跟进0057；原0056记录保留为初始观察证据。

审查发现并修复：兑换确认/刷新期间账号切换隔离、预检遗漏独立资金门禁、开发版尚未进入生产的有界完整 TRON 快照重试，以及正式分支缺失的手动钱包配置覆盖层。均补有回归证据，先通过领域规格复核，再通过质量/安全复核。TRON 修复与配置覆盖层尚未部署，不把源代码整合等同于上线。
