# 生产移动续期恢复执行计划

用户明确授权服务端恢复完整登录续期兼容及重试保护。沿用已批准ADR0080，不改认证策略。root独占命名验证目录与生产三文件增量，独立worktree codex/refresh-restore用于测试/审查，不覆盖主目录或其他任务。

1. 冻结实时API/worker镜像和完整源码身份、数据库schema及恢复字段，保存服务器私有配置和备份。
2. 对真实生产源码运行已有ADR恢复回归，记录422/缺参数的RED；从已审核实现提取最小3文件增量，保留生产无关接口和管理员策略。
3. GREEN验证同operation重试、不同operation重用、过期/撤销/封禁优先、结果推进、并发、旧请求、管理员隔离和日志。领域规格审查后质量安全审查。
4. 以当前API/worker镜像覆盖精确清单；隔离恢复最新备份，检查既有行指纹与真实PG重试/并发。不执行迁移（现网0087及两列已存在），既有迁移镜像缺口不得假称补齐。
5. 仅切换API/worker，验证全源码/环境身份、其他容器不变、双侧HTTPS和新旧刷新结构兼容；不得用真实账户制造凭证或复活撤销会话。保留故障快照，但旧不兼容镜像不作为正常回退目标；失败时仅在恢复可用性必要时受控回退并明确协议仍故障。
6. 更新报告/任务/恢复索引。无需新APK或清数据，用户复验朋友圈/钱包/资料。
