# 管理员操作密码与钱包后台简约界面

沿用用户已批准的人工钱包执行目标。用户于2026-09-08明确选择独立固定操作密码，并要求 Apple 现代简约风格。认证决策见 ADR-0014，Figma 远程同步沿用先前明确暂缓的决定，不声称已同步。

## 范围与分工

root负责方案、迁移编号、共享配置/路由注册/OpenAPI、前端界面和发布；单个实现代理负责分配的身份服务与认证接线，独立代理依次进行领域及安全审阅。不得同时编辑同一文件。

- [x] 核对当前认证调用路径，明确仅替换管理员路径；为凭证设置、修改、验证及失败限流写RED测试。
- [x] 独立哈希凭证与版本、近期登录和当前登录密码核验、事务内版本复验、追加式审计/Outbox；0054版本由root独占分配。
- [x] 管理后台专用认证状态和设置接口；所有管理员人工付款/候选哈希/事故/启停/交接命令使用显式operation_password，旧用户MFA不变。
- [x] 重做人工钱包区域：轻灰背景、白色分组面板、主状态与出款队列、独立安全设置；精确金额和锁定目标优先，技术摘要可展开但提交前可完整核对。
- [x] 点击即时反馈、短促可中断过渡、清晰加载/失败/未知结果；键盘焦点、移动布局、减少动态效果与高对比模式。
- [x] 前端不得保存或裁剪密码；敏感输入提交后清空；请求恢复仅保存原安全参数与幂等键；切换账号清除显示凭证。
- [x] 领域审阅后安全审阅；集中测试、完整verify.ps1、PG迁移/回退与并发验证、实际浏览器视觉与交互验收。
- [x] 生产资金关闭发布已完成；不代设密码，不生成默认凭证，不删除旧凭证，不解除其他资金门禁。
