User explicitly authorized implementation and production publication on 2026-09-11; installed baseline is currently published Android; include iOS; encrypted media retains stable content hash across devices.
Architecture: retain Matrix SDK authoritative local history and E2EE; business profile/local feed snapshots publish independently; bounded shared media cache, local-first pages, incremental presentation. Reference ../specs/2026-09-11-chatflow-performance-plan.md in full.
Baseline: isolated codex/performance-20260911 combines wallet/chat 7bc73ec3 and main 0f65614d (iOS binding fix). No unrelated dirty main files imported.

Each task follows: inspect current path → failing regression with intended red result → implementation → focused tests/analyze → specification review → quality/security review → commit explicit owned files. Logs only docs/verification/artifacts/2026-09-11/performance/.

- [ ] PERF00 Baseline: production versions/settings and artifact references (read-only), tools/locks, deterministic 500-room/1000-member/50000-history workload; FrameTiming/cache/refresh counters without private data. - [ ] PERF01 Avatar: profile_repository.dart, matrix_user_avatar.dart, avatar_url_resolver.dart, ui/foundation/avatar_cache.dart, corresponding tests. Independently publish profile and contacts; preserve scoped disk hydration/generation, tri-state removal and mutation ordering. Failed resolutions retry boundedly with lifecycle cancellation, credentials scoped/current, stable disk key; subscriber refresh after success. Test failure recovery unchanged props, profile succeeds/contacts fails, avatar removed/account swap.
- [ ] PERF02 Offline chat: room_page.dart load sequence, dedicated load state helper if useful; tests. Local timeline displays despite markRead/emoji/reminder failure. Preserve empty/offline/retry, SDK local history and account boundaries; no hidden errors or network auth bypass.
- [ ] PERF03 Input: room_draft_store.dart, wechat_composer.dart, room_page.dart tests. Typed draft copies before debounce, serialize at flush; preserve IME/composition and lifecycle flush. Ordinary input rebuilds no message rows; member search only @ path.
- [ ] PERF04 Timeline: room_timeline_controller.dart, adapter interfaces only if needed, room_page.dart/tests. Stable ID index and local echo reconciliation, no-op suppression, incremental updates and bounded UI projection; SDK history order/gap/reply anchors/redactions preserved. Add large workload/cost assertions and no echo duplicate regression.
- [ ] PERF05 Media: media_cache.dart, scheduler/budget helpers, image/video cells/poster cache tests. Shared bounded resource scheduling, requests join and visible priority promotion, account hash objects reused, video file path avoids full memory duplication, bounded decode/animation, offscreen cancel by ownership. Test known hash cross-account isolation, same-content roundtrip, cache clear/generation, concurrency and budgets.
- [ ] PERF06 Moments: cache_repository.dart, moments_page.dart, persistence and tests. Persist viewed pages/cursors/tombstones using existing SQLite conventions, account/private invalidation, local-first offline pagination; no whole feed reset. Expansion/migration preserves existing cache.
- [ ] PERF07 Lists/profile/viewers: matrix_home_page.dart, profile subscriptions, room/media viewers, tests. Dirty room projection and stable ordering; peridentity refresh; current image priority and adjacent bounded prefetch; one active video. Preserve navigation and room image order.
- [ ] PERF08 Verification: focused tests, shared full flutter suite/analyze, preflight then scripts/verify.ps1; Android/iOS platform compilation and performance scenarios. Capture red/green source identity, realistic caveats, review specification before quality. No passing claim from compilation alone.
- [ ] PERF09 Delivery: re-read live versions and signing workflow; source builds, Android conventional rebuild/alignment/stable signing, iOS verified signing channel; immutable upload then separate platform manifests/settings/audit. HTTPS/SHA/range/rollback gates. Pending iOS external signature blocks only iOS publication, never replace it with unsigned IPA. Do not mark goal complete until requested platforms/requirements have sufficient evidence.

Ownership: parent owns plan/task records, production queries, baseline setup, integration and delivery. One implementation subagent at a time owns explicit module files; read-only reviewers may run independently. No concurrent same-file edits or shared build output mutation.
