# 钱包绑定、点钻提现与支付密码实施计划

用户授权：2026-09-11 本任务要求整体替换钱包 UI、绑定后充提、复用支付密码；用户补充确认 1 点钻 = 1 USDT、零手续费、最低提现 10 USDT。标题保持“钱包”。

1. 追踪现有入口、绑定门槛、余额、兑换及提现事务、支付密码授权。已定位旧钱包和 TRON 子页并存，充提为分段控件，提现仅消费 USDT 且未使用用户支付密码。
2. Flutter 将 TRON 卡片作为主钱包，改绑图标置于卡片；充提独立页面，未 ACTIVE 或未就绪为灰色禁用。提现显示服务端点钻余额，全额填入；恢复原订单和账号隔离。
3. 服务端通过公共财务接口实现点钻提现，复用既有 1:1 兑换及储备约束，PIN 授权绑定完整意图并在金融事务内消费。重试不得重复兑换/冻结；取消及失败保留可追溯资金状态。红包/转账行为保持。
4. 同步 HTML UI、接口契约与 ADR。受保护服务端变更先领域审阅，再质量/安全审阅。
5. 按用户此前“无需自己测试”边界不操作真实资金或真机功能；记录未执行验收。因本次新增跨资产事务且线上已有充提开关，补充必要隔离SQLite/PG金融校验（已向用户说明）；执行编译、契约/源码审查和必要构建安装校验，生成稳定签名 debug APK，推送 Mi 6，明确服务端候选与部署状态。
