# MI 6 相册保存与视频索引兼容修复

用户反馈授权继续修复及验证，沿用功能优先、暂不更新 Figma。拥有 AndroidManifest/媒体平台能力、图库筛选、图片/视频保存及共用提示组件、相关测试和验证文档；不修改其他任务内容。

1. 保存失败：MI 6 API 28 已授予 READ，但安装包移除 WRITE；恢复仅 <=28 写权限，保存时请求，现代 Android 不申请旧权限。
2. 视频遗漏：设备有两段 MP4，宽高为 NULL；插件默认宽高 SQL 比较将其排除。设置视频 ignoreSize，保留时序和媒体类型筛选。
3. 保存先检查权限，失败分类为权限/读取/保存，图片与视频共用提示组件。
4. 群二维码线上缺失接口已复核；提示改为服务尚未部署，不要求用户找群管理员。部署仍是独立未完成项，不绕过服务端令牌机制。
5. red/green、分析和构建验证，更新 debug 包到原 MI 6，保留数据。真实保存需要用户同意系统权限，不能由 adb 代授权。
