## 设计与边界

正常启动保留系统启动画面至本地安装校验和数据库恢复完成，不增加检查页面；真实初始化错误仍可重试。Matrix 初始化等待本地数据库而不等待首次网络同步。同账号缓存预览沿用现有只读限制，远端会话校验和密钥恢复不绕过。头像确定性地址先命中现有磁盘缓存，再后台确认服务能力；身份缓存按账号读取。会话预览必须基于已持久化的真实事件，真实撤回标记不能清除或复活。

## 批次与文件所有权

1. 主执行者：`core/installation_startup_gate.dart`、`features/matrix/matrix_client_factory.dart`、`main.dart`、必要的缓存组合组件和对应测试。先验证网络阻塞/检查页面红测，再最小修复。
2. 头像独立实现：`features/matrix/matrix_user_avatar.dart`、`matrix_e2ee_client.dart` 中头像能力、对应头像测试。同步缓存地址与后台能力确认，保持生命周期及凭据隔离。
3. 预览独立排查：新增磁盘重启测试；取得可复现根因后限定 SDK 持久化修复范围，补充真正撤回、历史回放和冷重启断言。
4. 主执行者集成身份缓存预览；定向测试、完整 Flutter 测试和分析；按变更影响复用未变后端门禁。规格审查后质量/安全审查；记录源码哈希与未进行的真机验证。
