# 红包优化第一批：现状与隔离基线

> 执行方式：本会话按步骤执行；不派生其他任务。用户已在审查后要求开始第 1 项优化。

**目标：** 量化现有红包领取的服务层竞争，作为是否重构的依据。

**设计：** 保留 PostgreSQL 领取、账本和 Outbox 事务。使用本任务新建的 localhost PostgreSQL 16.9 容器、合成账号和独立数据库测量现有服务；不修改资金算法、权限、API、生产配置。基线不是生产容量认证。

**方案比较：** 优先测量并缩小既有事务成本；Redis 限流/削峰须在压测证明收益后立项；Redis 预占及异步账本必须独立 ADR 定义持久性、退款栅栏与返回语义，本批不实施。
