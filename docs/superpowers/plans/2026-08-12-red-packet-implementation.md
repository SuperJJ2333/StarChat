# 六合通 Phase 5 彩币红包实施计划

## 目标
支持私聊/群聊等额与拼手气 CAIBI 红包，24 小时有效，未领取退回，异常红包由授权客服/管理员撤回，不收费。

## 数据与资金流
创建时将发送者彩币转入红包专用托管账户；领取时从托管账户转给领取者；过期或撤回时只退还未领取份额。Matrix E2EE 卡片只携带不透明红包 ID、版本和安全提示。

## TDD 任务
1. 红包、份额、领取唯一约束及迁移。
2. 精确到分的等额/拼手气预分配，份额总和严格等于总额。
3. 幂等创建、并发唯一领取、24 小时过期、授权撤回。
4. API、E2EE 卡片 JSON Schema、OpenAPI 和 Worker 过期任务。
