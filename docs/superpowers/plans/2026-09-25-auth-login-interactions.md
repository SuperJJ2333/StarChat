# 登录与注册交互修复计划

**授权来源：** 用户 2026-09-25 提出的六项登录/注册页面修复。此计划只改变客户端显示和本地交互，不改变验证码、登录或注册的服务端限流与鉴权。

## 根因与范围

1. 429 的 `retryAfterSeconds` 在 `LoginController` 被压成一次性文案；登录页没有截止时间与计时器。
2. 登录页用手机号有效性禁用取码按钮，因此本地格式校验无法从按钮触发；格式错误复用页面底部 `_error`。
3. 登录/注册列表没有点击空白处取消焦点的行为。
4. 取码按钮没有清晰轮廓/按压反馈；共享背景始终绘制浅色图片。

## 实施顺序

1. 在 HTML demo 和 UI registry 表示非法手机号可点击、字段下错误、取码按钮轮廓与反馈、深色背景；维护现有冷却及减少动态效果语义。
2. 先写 Flutter 用户可见的失败用例：两种登录的 429 倒计时、手机号格式错误位置与无 API 请求、点击空白处收键盘、深色背景、取码按钮可交互；保留注册页原有字段错误逻辑。
3. 在 `LoginController` 保留 429 的 typed 秒数。登录页以截止时间计算剩余秒数，每秒刷新显示，销毁时取消计时器，过期不自动发请求。输入编辑可清除字段格式错误。
4. 在共享 UI 层处理点击空白处取消焦点、暗色背景与带轮廓取码按钮；登录和注册页面使用该控件。保持 OTP 冷却与请求状态阻止重复发送。
5. 运行聚焦红绿测试、Flutter analyze/相关测试、HTML 测试、UI contract 和仓库适用门禁。先规格审查，再质量/安全审查，记录真实退出码。

## 验收边界

- 非法手机号点击“获取验证码”仅显示手机号字段错误，不发短信；有效号码仍须同意协议，服务端限频照常生效。
- 429 倒计时按 `retryAfterSeconds` 与真实时间推进；后台恢复显示正确剩余时间，到期不自动登录。
- 共用认证脚手架使登录、注册与验证码页统一呈现暗色背景；浅色资源和卡片内容保持原有语义。按钮按压反馈尊重减少动态效果设置。
- 不改 Business API/Matrix 协议、账号数据或鉴权规则；不发布生产包。
