# 2026-09-14 启动加载、账单筛选对比度、转发异步与闪照

## 范围与根因

1. **启动全屏“正在加载”**：`AppHome.build` 在 `!_matrixReady` 时返回整屏 `CupertinoActivityIndicator`，通讯录 tab 在 identity cache 未就绪时同样整 tab 转圈；每次冷启动/账号切换必现。修复：常驻渲染 TabScaffold 外壳，仅消息 tab 在未就绪时给轻量行内提示，其余 tab 照常可用；不做全屏阻塞。
2. **账单筛选按钮对比度**：选中态 `CupertinoButton(color: brandPrimary)` 叠加默认绿字 → 绿底绿字。修复：选中=品牌绿底+白字；未选中=浅表面+细边框+品牌绿字；按下/禁用态保持可辨。
3. **转发 5 秒等待**：a) 编辑图片路径 `_finish()` 先同步 `_export()`（PNG 编码数秒）再开转发选择器 → 改为选择器即开、确认后在选择器发送态内后台导出再入队；b) 转发确认后源房间只有一次性 toast『正在发送』，工作队列下载/上传期间无任何可见状态 → 订阅 `matrix.outgoingWork`（ChangeNotifier），按批次汇报『已转发/转发失败』。
4. **相册多选与闪照**：
   - 多选上限 9 已存在（GallerySelection）；新增滑动多选（从角标起按下滑过即选，超限提示），保留点击预览。
   - 大图预览新增『闪照』按钮：以 `extraContent: {'flash':'1'}` 发送图片事件。
   - 展示：`RoomMessageViewModel.isFlashPhoto` 解析 content.flash；气泡=马赛克缩略图（低分辨率解码+最近邻放大）+居中闪电 icon；未看过时点击进入闪照查看页（马赛克+『长按屏幕可查看 5 秒』），长按显示原图+右上 5 秒圆圈倒计时，松手/超时回马赛克并标记已看（SharedPreferences，按账号键）；已看后气泡加『闪照已销毁』且不可再打开；闪照消息禁止转发（菜单隐藏+批量过滤）。

## 不做

- 不动业务 API/财务逻辑。
