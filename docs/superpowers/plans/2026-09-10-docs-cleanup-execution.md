## 执行

1. 根据已批准审核清单整理文档导航，合并 ME.md，旧流程标退役，保留历史事实和链接。
2. 以已有 inventory 为候选，重新核验精确路径、链接、修改时间、活动进程和文件清单。2026-09-10 主题与长期发布工具不删除。
3. 对 2026-09-10 之前的 build/decoded/verified-decoded 等散文件目录先创建无损 ZIP 和逐文件 SHA256 清单；重新读取 ZIP 每个成员验证，再核对原目录未变化，才用 PowerShell Remove-Item -LiteralPath 清理精确目录。
4. 原始用户 APK 移入具名样本目录并验证 SHA256；已有 ZIP/bundle 备份原址登记长期归档，不擅自上传外部位置，不删除唯一恢复资料。金融审计、E2EE、发布回滚证据保留，即便压缩归档也保留全部字节。
5. 只使用已核实的 CodeGraph 本地配置方式排除生成目录，保留正式脚本；验证配置与索引效果。
6. 规格符合性先审，再质量/安全审查；验证新增链接、归档哈希、删除清单、空间统计和清理脚本的拒绝越界/归档失败不删除行为。产品未改变，不为文档整理启动无关产品发布测试。
