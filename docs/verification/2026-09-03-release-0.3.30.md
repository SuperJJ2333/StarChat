# 0.3.30 发布验证（2026-09-03）：后台/锁屏通知三层加固

## 背景

0.3.29 的 dataSync 前台服务保活后，用户复测后台/锁屏仍无通知。
三层补强：息屏唤醒锁（前台服务不阻止 CPU 休眠/WiFi 低功耗断连）、
看门狗自愈、电池优化白名单引导；后台来电改由系统通知渠道发声。

## 变更

| 层 | 文件 | 内容 |
| --- | --- | --- |
| 原生 | `MainActivity.kt` | `chatflow/keepalive` 通道：WakeLock+WifiLock（API 34+ 低时延模式）、电池优化查询/申请 |
| 原生 | `AndroidManifest.xml` | `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS` |
| Dart | `sync_keepalive_service.dart` | `KeepAliveHooks`（可注入）+ `MethodChannelKeepAliveHooks` + `KeepAliveBatteryGateway` + 10 分钟看门狗（`runWatchdogTick` 重申 FGS+锁） |
| Dart | `call_notifications.dart` | `calls_ring` 渠道（chatflow_ringtone.ogg）+ `showIncoming(ring:)` + 锁屏 public 可见性 |
| Dart | `call_alerts.dart` | `SoundServiceCallAlertDriver.audible` 门控（后台静音应用内循环，回前台恢复） |
| Dart | `app_home.dart` | ring:true 接线、audible 门控、电池优化一次性引导（`keepalive.battery_prompted_v1`）、paused/resumed 重申保活 |
| 资产 | `build_notification_sounds.ps1` + res/raw | `chatflow_ringtone.ogg` |

## 用户侧验收要点（真机，用户自测）

1. 应用内弹窗更新到 0.3.30；首次启动出现「后台消息保障」引导 → 去设置
   → 系统弹窗允许忽略电池优化。
2. MIUI：设置→应用管理→畅聊→自启动 开启；省电策略=无限制。
3. 锁屏后由另一账号发消息：锁屏通知+提示音；拨打语音/视频：全屏来电+
   系统铃声（不依赖应用内播放器）。
4. 前提：系统通知权限已授予（0.3.28+ 引导过）。
