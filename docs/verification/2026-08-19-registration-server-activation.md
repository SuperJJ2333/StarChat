## 验证码重试幂等键与长度提示修复（2026-08-20）

- 根因：Flutter `BusinessApiClient.verifyEmail` 用 `verify:<registration_session>:code` 作为所有验证码输入的同一挂起幂等操作键；改变验证码后仍携带同一 `Idempotency-Key`，服务端因此判定同一键对应不同请求体。
