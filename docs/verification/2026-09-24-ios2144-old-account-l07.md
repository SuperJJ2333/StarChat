# iOS 2144 旧账号 L07 真机脱敏取证

2026-09-24，故障 iPhone（用户确认 iOS 16.7.16）以已连接的 Windows USB 连接现场复现一次。用户在 0.3.102/2144 点击旧账号登录后再次看到 L07；同一手机新账号可登录。旧账号的 L07 在安装 2172 之前已出现。

## 采集与隐私边界

- 先确认设备已配对（只输出设备数量 1），再用 `idevicesyslog --no-colors -x -m E2EE_ -o <验证目录文件>` 限定允许列表事件；没有采集全量系统日志或消息内容。
- Windows 工具包为 `L1ghtmann/libimobiledevice` release `suite-exe-21d57a9`，GitHub 资产 SHA256 与下载字节一致：`948d20c5f6460ab9d9ac6b5fdeba00ddde0c62f59882e1e1e577ed16b3ae8abe`。原始筛选日志在提取下列字段后已被覆盖为说明文字，未提交哈希身份值；采集器和下载用 SOCKS 隧道均已停止。
- 本地脱敏 JSON 为 [sanitized-evidence.json](artifacts/2026-09-24/ios2144-l07-diagnostic/sanitized-evidence.json)，SHA256 `f57ef4763b9c50d990b558575dd6fe1bb9597d485a12ea70a75939c05362f5eb`。该 artifacts 目录由 Git 忽略；本页完整记录可复核的非敏感事实。

## 观察

| 设备日志时间（+08） | 事件码 | 阶段 | 结果 |
| --- | --- | --- | --- |
| 20:19:57.283798 | `E2EE_ACCOUNT_SELECT_BEGIN` | account_selection | success |
| 20:19:57.714066 | `E2EE_CONTINUITY_FINGERPRINT_MISMATCH` | continuity | failure |
| 20:19:57.714128 | `E2EE_ACCOUNT_SELECT_CONTINUITY_MISMATCH` | account_selection | failure |

三条事件的本地加盐 Matrix 用户标识相同，仅记录这个布尔判断，没有保留标识值。开始和选择失败同一 trace；连续性读取是嵌套操作，另起 trace。用户确认三条事件来自这次点击登录。

## 源码归因与局限

- 2144 的发布源码为 `7d1f15b5`。`login_controller.dart` 在业务登录后将 `matrix.selectAccount` 失败显示为 L07。`matrix_client_factory.dart` 仅在 `binding.ed25519Fingerprint != fingerprintReader(client)` 时发 `E2EE_CONTINUITY_FINGERPRINT_MISMATCH`；接着抛身份错配，`matrix_e2ee_client.dart` 拒绝发布这个 client。**直接失败条件已由真机与唯一源码分支同时确认。**
- 该分支不等价于已证明“旧数据库被删除”“Keychain 残留造成”“签名造成”或“某一版源码首次写错”。指纹何时分叉、原绑定对应的旧加密库是否还在，现场没有安全证据。不能自动把新指纹写回旧绑定或跳过比对；那会接受另一份 Olm 身份并可能令旧聊天密钥无法恢复。
- 2144 已包含 9 月 11 日卸载重装与 9 月 16 日 device ID 轮换修复；自动测试曾覆盖模拟路径，未覆盖当前真实设备状态。2172 启动前的另一个错误没有本次同级事件，单独保留为待验证。

本次为只读诊断，无运行源码修改、无数据库或 Keychain 清理、无构建和生产发布。`git diff --check` 通过；执行代码测试不适用。平台工具是 Windows 10 / PowerShell 7 / Python 3.12.10；iOS 设备版本来自用户报告，未从设备接口额外导出。
