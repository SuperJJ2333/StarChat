# 0.3.80 / 2084 交付验收汇总

本报告区分源码修复、自动化验证与用户设备验收。iPhone 15、iOS 26.6 沿用用户原始描述，当前安装版本为 0.3.69 / 2073；不把 CI 的 iOS 26 模拟器当作该手机。

## 1. 语音本机无法播放

- **问题现象**：本机发送成功、对方能听，本机自己发送及接收的语音不能播放。
- **复现步骤**：录音发送后立即自播；播放接收语音；暂停恢复、快速切换两条消息；缓存成功后断网重播；切换听筒与扬声器。
- **根因排查**：锁定的 Darwin 播放依赖在开始/恢复时缺少显式音频会话激活保证；共享控制器存在下载取消与迟到播放竞态；Android 听筒未明确使用通信模式。上述为源码和红灯测试证实的缺口，尚不能断言是用户手机的唯一原因。
- **修改要求与实现**：原生会话在播放/恢复前配置并激活，尊重正在进行的通话；播放操作串行，过期任务不能停止新消息；带正确后缀的私有临时文件在释放后清理。保持原有加密下载和缓存边界。主要文件为 `voice_playback_controller.dart`、`room_page.dart`、`AppDelegate.swift`、`call_ui_manager.dart`。
- **验收标准与结果**：控制器、路由和缓存自动化已通过；iOS 完整原生编译已通过。真实 iPhone 的音频听感、蓝牙、在线/离线加密附件与连续播放仍待覆盖升级后验收。

## 2. 切换账号保留聊天记录

- **问题现象**：原先切换账号可能走清除本地 Matrix 存储路径；失效凭据处理也可能清除 SDK 数据。
- **复现步骤**：账号 A 收发消息后退出，登录 B，再登录 A；A 离线期间从另一账号发送消息，检查恢复与同步。
- **根因排查**：旧存储绑定单账号，切换与登出复用破坏性清理；SDK 默认失效令牌恢复语义与“保留历史”要求不一致。
- **修改要求与实现**：按 homeserver 与 Matrix 用户 ID 隔离数据库、加密存储和恢复材料；旧数据库原路径迁移绑定，不搬移或删除。切换前停止旧同步、关闭旧连接，再打开目标账号；令牌失效保留数据库和现有设备密钥，重新认证后继续同步。主要文件为 `session_store.dart`、Matrix factory/adapter、仓内 Matrix SDK `client.dart`、`IOSSecureSession.swift`。
- **验收标准与结果**：真实 SQLite 的 A→B→A、密钥连续性、同步事件去重与顺序测试通过。实际用户账号跨设备离线消息与历史解密仍待真机测试。

## 3. L03 与单设备在线

- **问题现象**：切换已有账号出现“聊天登录未完成(L03)”；需要后登录设备顶掉前设备且保留本地历史。
- **复现步骤**：同设备 A→B→A；同账号先登录设备一再登录设备二；并发或超时后重试登录，检查哪个令牌仍有效。
- **根因排查**：L03 不能直接证明账号被其他设备占用；旧客户端包含切换清理失败路径。业务会话与 Matrix 令牌原先缺乏一个覆盖所有登录入口的统一替换协议。
- **修改要求与实现**：业务服务消费一次性登录授权并检查会话代次，私有 Synapse 模块按用户串行完成新登录和旧令牌撤销；公网原生发令牌入口封闭。客户端收到 `SESSION_REPLACED` 明确提示并退出当前登录态，保留账号存储。重新登录复用本设备已有加密身份。`matrix-session` 仅做验证，不用迟到的直接 DELETE 撤销新设备。
- **验收标准与结果**：真实 Synapse 1.132.0 + PostgreSQL 16.9 的 38 项检查通过，覆盖旧 access/refresh 撤销、保留同设备公钥、并发代次、HTTP 超时与重启防重放；生产发布及双真机顶号尚待完成。旧 iPhone 2073 应先覆盖升级，再执行真实账号顶号测试，避免旧客户端自行清除存储。

## 4. 视频自动压缩与发送

- **问题现象**：拍摄与相册的判断及发送路径不同，以原片或减量比例判断，可能提前拒绝可压缩视频或放行超限产物。
- **复现步骤**：分别拍摄和选择视频；验证普通压缩通过、普通超限转激进、两轮仍超限、明显长片预判、网络失败重试及临时文件回收。
- **根因排查**：未统一使用最终文件大小；现有插件的预设不能落实全部码率/帧率参数；相机重试闭包可能引用已删除源文件。
- **修改要求与实现**：所有视频共用设备端压缩管线，不显示压缩确认；普通档超限自动激进编码，最终按实际文件长度校验 20 MiB。时长与最低码率预算用于提前拒绝明显不合要求的视频。上传前保留经验证的加密发送输入供重试，及时删除应用拥有的废弃文件，保留相册原件。后端不接收明文视频做压缩。
- **验收标准与结果**：Dart 边界、两轮压缩、预判、清理和重试测试通过；Android 与 iOS 原生代码编译通过。真实大视频的音画同步、旋转、HDR、硬件编码效果及存储回收仍需设备验收。
