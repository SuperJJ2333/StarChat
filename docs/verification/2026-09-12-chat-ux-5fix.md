# 聊天体验 5 项修复（表情/复制/高亮/引用返回/长按选择）交付记录

日期：2026-09-12。基线：main @ `dfaae332`（含 0.3.84/2088 集成与 L07 双层修复）。
实现 + 自测 + Mi 6 debug 部署；微信最新版为体验基准。

## 实现

| # | 需求 | 实现 |
|---|---|---|
| 1 | 输入框 emoji 彩色显示 | `EmojiEditingController`（`lib/ui/chat/emoji_text_controller.dart`）重写 `buildTextSpan`：表情目录内 emoji 以与气泡一致的 fluent 彩色/动态字形渲染（Flutter 3.44 editable text 原生支持 WidgetSpan）；保留 IME composing 下划线与光标/选区行为。根因：Mi 6 等老系统 emoji 字体缺 🥲 等新字符，气泡侧早已用矢量字形而输入框走系统字体。room_page `input` 控制器替换为该控制器。 |
| 2 | 复制转 [表情名称] | `lib/features/emoji/emoji_shortcode.dart`：全量 225 个去重字素的中文名映射（🥲→[微笑] 按需求示例）。`emojiToShortcodes()` 应用于：长按复制（整条与局部选择共用 `_handleMessageAction.copy`）、多选复制（新增 `_copySelectedMessages` + 选择栏复制按钮）。映射外字符原样保留，已有 `[xxx]` 不受影响。 |
| 3 | 气泡强调效果 | 行结构重构为 `Stack(clipBehavior: none)` + `MessageHighlightPulse`（`message_highlight_pulse.dart`，1500ms 时序：淡入→闪一下→保持→淡出归零，无残留）。高亮层 `Positioned(left:-md,right:-md,top:-4,bottom:-4)`：负水平偏移抵消列表水平内边距实现全宽；±4pt 垂直外扩恰好止于相邻气泡 8pt 间隙中线。适用所有消息类型（高亮在行容器层）。 |
| 4 | 回到引用位置弹窗 | `quote_return_banner.dart`：与 @提醒弹窗 `MentionBannerButton` 完全同款（同 padding/圆角 12/brandPrimary 12% 背景/12px 箭头图标/3px 间距/12 号 w600 字体），方向箭头向下。点击引用跳转成功后（`_jumpFromQuote`）在时间线 Stack 右下角（bottom:76，输入框之上）显示；点击 `_returnToQuoteOrigin()` 返回引用发起消息并高亮，弹窗消失；再次引用跳转自动替换目标。 |
| 5 | 长按复制选框 | `message_text_selection.dart`：文本消息长按时选框+菜单同现（原长按菜单集合）；基于消息 `RenderParagraph` 的 `getBoxesForSelection/getPositionForOffset` 绘制选区与定位手柄；左右手柄拖动（跨行/emoji/表情代码）实时更新，拖动中菜单淡出 + `CupertinoMagnifier` 放大镜跟随，松手菜单恢复并按选区自适应；局部选择时菜单切换为 复制/全选/引用/转发（顺序按规格），操作以选中文字为对象（复制走映射转换；引用/转发构造文字替换的消息视图副本，事件 ID 保持关联原消息）；全选恢复整条；空白点击/列表滚动（translucent 穿透并取消）/切换会话（dispose）/发送消息（`input.clear` 前）均取消。 |
