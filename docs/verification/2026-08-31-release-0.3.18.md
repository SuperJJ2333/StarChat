# 0.3.18 发布：图片页相册/视频、语音播放动画、红包详情修复与更新推送（2026-08-31）

## 需求与实现

### 1. 图片选择页

- **时间倒序**：相册查询统一附加 `FilterOptionGroup(orders: [OrderOption(createDate, asc: false)])`，最新创建的图片/视频显示在最上方。
- **顶部“最近图片(↓)”**：导航栏中部为相册下拉按钮（默认“最近图片”），点开 CupertinoActionSheet 子列表：最近图片（默认选中✓）、本地视频、Camera、Screenshots 等本地图库分类（`DeviceGallerySource.loadAlbums`，onlyAll 视频→“本地视频”，非 all 相册逐项列出）。切换相册重建分页器并清空勾选；`albumsLoader`/`pagerFactory` 均可注入测试。
- **视频发送**：网格支持视频条目（缩略图 + 时长角标 + 播放图标）；发送默认**压缩**（`video_compress: ^3.1.4`，480p `Res640x480Quality`，显著降低上行与服务器存储/带宽负担；压缩失败回退原文件但同样受 20MB 兜底拦截）。
- **原图开关保留**：勾选“原图”后以原始大小发送，但**单个视频 >20MB 拦截**（`maxOriginalVideoBytes`），弹窗“视频过大…请关闭原图后重试”，页面不关闭；压缩发送不受限。图片原图不受该限制。
- `MessageTypes.Video` → `RoomMessageKind.file`：发出的视频在会话中呈现为附件条目。

### 2. 语音消息播放动画（QQ 式）

- 气泡内音纹改为**自适应竖条波形**（按宽度 5~14 根，正弦包络，`SizedBox` 显式撑高修复 CustomPaint 高度塌缩）。
- 播放中一道高亮**从左到右扫过音纹**：已扫过条实心白、未扫过半透明白，扫过时长=语音时长；点击播放在 `didUpdateWidget` 触发，播放中滚回视口从中段继续。
- `VoiceAudioEngine` 新增 `completed` 流（audioplayers `onPlayerComplete`）：播放自然结束自动复位为空闲态（修复此前“播完后气泡仍在动”的问题）。

### 3. 红包“领取详情”修复

- **服务端**（business-api）：`RedPacketService.detail` 注入 `ProfileService.read_public_profiles`，为每个 claim 补充 `nickname`/`username`/`avatar_url`（自定义头像，签名 URL），并补充 `sender_nickname`/`sender_username`/`sender_avatar_url`；资料读取失败静默降级为基础详情。
- **客户端**：展示优先级 **备注（查看者自己的联系人备注，仅本人可见）→ 昵称 → 用户名 → 好友**；头像 = 领取人公开头像 → 联系人头像。此前非联系人一律显示“好友”且无头像的问题修复。

### 4. 更新弹窗推送

- 版本升级 **0.3.18+21**；构建三架构签名 APK 并上传 `/opt/starchat/frontend/downloads/`，`latest-arm{32,64}.apk`/`latest-x86_64.apk` 别名同步刷新。
- 管理端 `PUT /api/v1/admin/app-update-settings` 发布（幂等键 `app-update-publish-0.3.18-20260831`）：`latest_version=0.3.18`、`latest_build=21`、`min_supported_build=3`、`apk_url=.../ChatFlow-0.3.18-arm64.apk` 与更新说明；容器内 `GET /api/v1/app-updates/latest` 回读 PASS。
- **客户端修复**：Android 分 ABI 包 versionCode 带 `abiIndex*1000` 偏移（如 x86_64=4021），`AppConfig.normalizeBuildNumber` 归一化后再与 `latest_build` 比较；否则旧客户端 4020≥21 永不弹窗。0.3.18 起后续版本可正常推送弹窗（0.3.17 及更早客户端的弹窗缺陷无法回溯修复，可通过落地页下载更新）。
