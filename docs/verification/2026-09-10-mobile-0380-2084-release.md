download-page detour no longer exists. The iOS row (`app_ios_*`) remains

iOS clients (asserted in the apply output), so this publication cannot leak
into iOS clients, and Android's 更新 button（弹窗与「设置 → 关于畅聊 → 版本更新」
共用同一 API 投影）goes straight to the APK.

Popup math: Android installed base ≤0.3.73 sees `0.3.80 > 0.3.73` → dialog;
2084 installs stay silent; nothing forced.
