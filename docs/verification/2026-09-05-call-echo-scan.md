# 通话路由与扫一扫交付

## 修改及根因

- 语音/视频呼入与呼出：权限通过后、建立媒体前应用界面的免提状态。依赖源码确认 Android AudioSwitch 默认扬声器优先且可能保留上一通的偏好，原先界面 speaker=false 与实际路由可不一致。覆盖旧外放残留、显式免提、拒绝权限路径。
- 未把本地 RTC renderer.muted 当作回声修复：所用原生 flutter_webrtc 的这个属性实际会关闭上行麦克风。Matrix 原有 echoCancellation/noiseSuppression 已开启；未盲目叠加采集约束。
- 发现页与消息页扫一扫入口改为 root navigator，遮盖底部标签栏。
- 扫一扫新增“图库”“我的二维码”；照片选择复用聊天 ImagePickerPage，照片单选、确认按钮“识别”，使用原始照片本地解码，不上传文件。临时副本在 finally 删除，视频不能进入解码。
- 照片模式的权限、相册查询、分页、恢复、有限权限管理均限定 RequestType.image；与聊天混合媒体模式分开缓存。聊天默认继续支持视频。
- 相机在图库/我的二维码/确认页期间暂停，返回时恢复；补充初始化尚未完成就打开覆盖页、扫码过程中退出页面的竞态处理。
