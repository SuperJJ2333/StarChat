# 0.3.27 发布：统一通知系统 + 邀请码统一 + 更新弹窗推送（2026-09-03）

## 发布内容

1. **统一通知与音频反馈系统**（PRD《ChatFlow 通知与音频反馈系统 V1.0》Phase 1）：NotificationCoordinator 统一协调声音/震动/角标/系统通知；前台横幅、@我与特别关注强提醒、勿扰时段、通知隐私三档、声音冷却与事件去重；语音/视频来电各自循环铃声与接通/结束提示音（assets/sounds/ 15 个规范音效，`scripts/build_notification_sounds.ps1` 可再生成）；修复自己发送消息后消息列表出现红点的问题；桌面图标角标聚合未读总数。详见 `docs/NOTIFICATION_SYSTEM.md`。
2. **邀请码统一**（规格 §6.2 修订）：全流程只有一套注册邀请码——注册页删除「好友邀请码」独立字段；「我」页展示固定的个人注册邀请码（`GET /api/v1/invitations/mine`，HMAC 确定性派生、默认 20 次/滚动 365 天）；好友注册消耗该码即自动建立邀请关系（复用 referral_bindings）；旧客户端 referral_code 参数过渡期兼容；Android 桌面角标由 flutter_app_badger（AGP 9 不兼容）替换为自建 MethodChannel + ShortcutBadger 1.1.22。
