# 0.3.26 发布：视频选择权限修复、聊天媒体优化、邀请码与交互改进 + 更新弹窗推送（2026-09-02）

## 发布内容（本次版本包含）

1. **视频选择权限修复（多次反馈的问题根因）**：AndroidManifest 补声明 `READ_MEDIA_VIDEO`——Android 13+ 图片/视频权限分离，此前只授予图片导致媒体选择器读不到任何视频（历次 Dart 层修复无效的真正原因）；选择器内视频条目显示"分:秒"时长角标。
2. **聊天媒体加载优化**：发送端自动生成 ≤800px/≤100KB 图片缩略图与视频封面帧（E2EE 加密附带），接收端气泡缩略图优先、点击查看原图（进度+重试）。
3. **邀请码**："我"页新增「邀请码」入口（设置上方），30 分钟轮换专属码 + 分享（复制/图片/微信/QQ）；注册页选填好友邀请码绑定邀请关系；服务端限流/防枚举/防重放。
4. **聊天交互**：上滑到顶自动加载更早消息（loading/"没有更多了"）；长按菜单宽度减半、语音/通话气泡不可转发、本地删除；更多面板点击面板外自动收起；语音/通话气泡文字统一黑色。
5. **长按拍摄录像**：短按拍照、长按录视频，自动带回发送区确认，发送前压缩（480p 策略、进度百分比、明确回退提示）。
6. **名称显示优先级**：私聊 备注>昵称；群聊 群昵称>备注>昵称。
7. **修复**：裁剪头像"确定"按钮被状态栏遮挡（Ucrop 主题退出 edge-to-edge 强制）。

## 弹窗生效逻辑

- 已发布客户端（0.3.25，归一化 build 2028）< latest_build 2029 → 启动后弹出更新弹窗，指向 arm64 APK。
- 更新到 0.3.26 后归一化 build 2029 = latest → 弹窗不再出现。
- `min_supported_build=3` 保持不变（不触发强制更新语义）。
- 0.3.17 及更早客户端构建号比较缺陷依旧无法回溯，经落地页下载更新（见 0.3.18 报告）。
