## Minimal correction

After creating the existing artifact directory, the test resolves its canonical absolute path before createTemp and before returning it from the fake PathProvider. Native PathProvider already supplies an absolute application directory; the fixture no longer feeds redundant parent segments to Windows directory enumeration. The temporary files remain under the existing approved verification directory.

Canonical paths alone did not fix the independent run: r4 had no persistence errors, but the second persist-done still arrived after the assertion during cleanup. The final wait therefore uses a Stopwatch with the same ten-second real deadline, yielding 16 ms for I/O then advancing one 16 ms frame. The former loop instead imposed a maximum of 100 progress pumps while sleeping 100 ms between them. It could exhaust its pump count while the real-I/O chain still needed additional widget-zone turns. The final fixture prints actual real elapsed time, pump count and total fake-time advance; it does not extend the real deadline. Both RawImages must still decode, both current references must still share exactly one HTTP source, and the later search result must reuse that source. No count is relaxed and no exceptions are ignored by the test. Runtime source, cancellation/publication rules, E2EE, dependencies and platform files are unchanged from 5988. All temporary bubble/preview tracing was reverted and remains only in diagnostic patch artifacts.
