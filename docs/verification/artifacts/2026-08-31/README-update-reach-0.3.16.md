# 2026-08-31 0.3.16+19 发布（更新触达第二轮修复）

问题：用户反馈"更新弹窗没有弹出 0.3.11 版本"。

根因（客户端触达链路三处薄弱）：
1. 更新检查只在 App 冷启动执行一次——长期驻留或后台返回不检查；
2. "稍后再说"的持久化记录会无限期压制同一 latest 版本的提醒；
3. 更老设备（更新检查功能上线前）本身无检查逻辑。

修复（0.3.15 已含 resumed 检查；0.3.16 追加）：
- 0.3.15：回到前台（resumed）触发更新检查（30 分钟节流）；
- 0.3.16："稍后再说"记录超过 24 小时自动失效，冷启动/回前台重新提醒；
- AppUpdateDeferStore 增加 clear；新增 defer 过期测试。
