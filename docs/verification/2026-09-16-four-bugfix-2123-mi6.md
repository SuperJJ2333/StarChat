## 4. 建议的真机验收用例

1. **朋友圈评论图片**：朋友圈 → 评论 → 相册图标 → 选图 → 发送。应能正常返回并带上图片；
   不再卡在相册页。可再试「取消/返回」是否正常退出。
2. **群聊转账**：群聊 → 转账 → 点收款人。列表**只能**出现本群成员；不应出现通讯录好友。
   选一个非好友群成员，应能正常确认并发送。
3. **专属红包**：群聊 → 红包 → 类型选「专属红包」→ 指定成员。成员应能显示头像与好友备注；
   选中后不应再弹「无法确认红包账号：当前会话暂不支持确认该群成员账号」。
4. **私聊转账**：私聊 → 转账。收款人应固定为对方、不可点击、无右侧箭头。
