基线：81554a9 + Matrix SDK 入库修复 dea2f55。用户授权自行修复并安装 Mi 6；本轮是对第三轮改动的有界复核，不等同于全部十项功能的端到端验收。

## 发现与修复

- 搜索页：旧查询翻页期间切换条件会使新页脚持续转圈。新增查询代次、开始/结束时重建页脚，旧请求不能修改新查询状态；立即搜索取消页面待执行的防抖，查询异常由失败态承接。
- 视频缓存：移除把安全文件名误当原始键再次转换的通用缓存枚举接口。房间接入独立 VideoPosterDiskStore，原始键索引与磁盘文件名分离，AES-256-GCM 加密、键名作为 AAD、每个实例随机内存密钥，磁盘无全局 LRU。缓存持有最多 32 MiB 封面文件字节及 256 项；引擎解码图片内存不计入此预算。内存淘汰仍能命中磁盘。
- 生命周期/竞争：串行化同键写入和删除；读取等待旧写入及清理结束；清理/替换后旧请求返回 stale，包括磁盘写入抛错的情况；新代次不再复用旧在途任务。房间撤回触发 evict，退出房间清理缓存及临时目录；页面重建不清理，房间实例重建允许重新加载。进程异常退出后内存密钥丢失，旧临时密文不可复用，由系统临时目录回收。
- 视频封面：拒绝 stale 结果，无发送端缩略图时从本地缓存的视频抽帧；Matrix 不可变事件 ID 用作稳定媒体版本。
- GIF：气泡可立即展示已有预览，随后加载原始字节，由解码器识别内容，避免 .jpg / image/jpeg 误标 GIF 永久停在静态缩略图。此策略会读取原图，首次大图可能增加流量；原图缓存继续复用。尺寸探测监听改为单次监听，源变化/销毁时移除，逐次释放 ImageInfo，避免 GIF 离屏后残留监听和帧句柄。
- 版本统一为 0.3.43+46；修正 Windows CRLF 敏感的源码/部署策略断言，并让既有在途取消测试等待加载器实际启动。
