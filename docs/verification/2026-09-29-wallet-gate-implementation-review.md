# 未绑定钱包充值门禁：实施级复核

日期：2026-09-29（Asia/Hong_Kong）。范围为已批准的 ADR-0077 补充、充值服务与 API、钱包域公开门禁及 PostgreSQL 16.9 隔离并发测试。本记录不授权生产发布。

## 领域复核：PASS

- 新充值申请在同一事务内锁定 `WalletBindingState`，核验 ACTIVE 绑定的账户、版本和生效状态；无绑定、待审核或不一致返回明确的 409。绑定写路径先持同一状态锁，所用锁序与现有钱包管理路径一致。
- 已完成的同键同载荷申请在当前付款配置、汇率和绑定检查之前返回原回执；不同载荷仍冲突。新申请强制读取官方付款配置，调用方没有关闭此门禁的参数。
- 成功仅创建 `SUBMITTED` 申请及既有审计、事务 Outbox，不直接改变余额或账本；被拒绝的申请回滚幂等占位、订单、成功审计与 Outbox。旧申请的查询和后续核对保留原有路径。

## 质量与安全复核：PASS

- 权限来自已验证的调用者身份；幂等键按账户隔离，跨账号查询/凭证操作继续拒绝。未绑定状态由服务端读取，客户端展示状态不能绕过门禁。
- PostgreSQL 16.9 隔离环境中，两种申请/改绑先后交错均观察到预期行锁；测试 3/3 通过。充值套件 109 通过、1 跳过。测试仅用合成账户和临时数据库，无生产资金写入。完整命令、RED 变异试验、GREEN 输出及容器身份见 [隔离并发记录](artifacts/2026-09-29/android-2191-followup/wallet-gate/pg16-concurrency-summary.md)。
- 独立领域及质量/安全复核确认无实施级阻断。此前设计复核指出的可跳过配置参数和旧单回放前的汇率请求，已在实现中消除。
