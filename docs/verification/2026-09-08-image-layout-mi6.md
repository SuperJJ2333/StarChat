# 图片贴边与大图适配 — Mi 6 debug

## 修复和验收

主工作区提交 `207d91ed`；同步至正式基线分支 `codex/image-layout-mi6`（`26eabbc1`），已推送。此次只修改两个图片 UI 文件及回归测试，不修改钱包或后端逻辑。

- `ContainImageBubble`：稳定预留框与实际图片比例不同时，原先居中绘制将空白分配到头像侧。现按收发方向对齐到头像一侧，保留 contain、不裁切、不改变缓存或消息行高度。
- `ImageViewerPage`：原先查看器按预览图固有尺寸布局；现在使用全部可用视口等比放大。增加双击三倍放大/再次双击复位、继续支持捏合拖动；视口变化时恢复适配。
- 不把横图拉伸为竖屏，也不默认裁切。比例不同仍会有上下背景留白；原文件内自带黑边不会被擅自裁除。

红测试：4:3、16:9 的收发图片到头像间距实际为 34.56/54.56dp，而非 8dp；大图宽 160dp，而非屏幕 400dp。绿测试覆盖收发方向、4:3/16:9/9:16、缺失元数据、400px 视口适配、双击与旋屏。24 项图片相关测试通过；全量 Flutter 1359/1359 通过；analyze 零问题。全量后仅将测试夹具由间接 image 依赖改为 dart:ui，随后重新跑了 24 项相关测试和 analyze；产品代码未再变动。
