## Operations note

The workstation's usual SSH route (local proxy 127.0.0.1:7897) failed at banner exchange for several hours. The user-supplied substitute subscription (HK vmess+ws) was diagnosed non-functional — inconsistent cross-resolver DNS and dead websocket backends — so distribution used the `jumper` (8.163.93.151) SSH jump route, which proved faster (~700KB/s). A temporary mihomo instance used for diagnosis was stopped; no persistent local configuration was changed. Recommend the user refresh/replace the dead subscription entries.
