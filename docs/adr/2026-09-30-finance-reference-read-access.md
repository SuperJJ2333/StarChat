# 财务客服结算参考汇总只读访问

状态：用户2026-09-30批准；规格/领域与质量安全审查均PASS。日期：2026-09-30。

## 用户目标与根因

用户要求财务客服的结算参考正常显示。当前生产 reserve-valuation 路由硬性要求 SYSTEM_ADMIN，而页面对财务客服显示该板块；403被笼统显示为储备暂不可用。本错误与 PASSWORD_RESET 提现保护不同，该路由当前不调用 SupportOrderSessionAuthorizer。

## 决策

- 保留管理员现有访问；增加已开通、ACTIVE、当前管理会话有效且有 FINANCE_SUPPORT 的客服只读访问。
- 客服返回页面需要的 caibi_face、caibi_reference_usdt、usdt_obligation 三项汇总；管理员完整既有响应保持兼容。
- 服务端校验当前管理会话、设备/令牌族、角色和开通状态，不信任客户端角色。此只读读取不使用提现保护和钱包写入grant校验；不授权结算写入。
- 继续用既有 Decimal 计算、字符串响应；估值缺失仍为null并显示暂无参考估值，不当成0。
- 页面分别呈现未登录、权限不足、网络/服务故障；其他结算与钱包权限不变。
- 未登录、普通用户、仅SUPPORT_AGENT、失效会话、角色撤销、无效开通拒绝。恢复保护中的有效FINANCE_SUPPORT允许该汇总读取，其他订单路径保持原策略。

## 验收与回退

先失败测试再最小修复；规格/领域审查后质量安全审查；focused tests和适用verify门禁。发布前核当前API/静态哈希，增量候选、镜像门禁、回退与其他容器不变验收。无迁移，无实际财务写入。回退仅API受影响文件和静态文案。
