# ADR-0010: USDT 与点钻双向兑换及 MPC 托管钱包

**状态：** 待书面审阅批准  
**日期：** 2026-09-06  
**替代范围：** ADR-0006 中“点钻与 USDT 严格隔离、不引入兑换”的决定，以及产品规格第 2、9.1、12 节中禁止兑换的部分  
**保留范围：** `CAIBI` 内部资产代码、点钻两位小数、USDT 六位小数、追加写复式账本、USDT P2P 与 USDT 红包禁令

## 背景

畅聊 ChatFlow 需要允许用户在 TRON 主网上充值和提现 USDT，并以固定 `1.00 USDT = 1.00 点钻` 的显示单位比例双向兑换。用户通过各自的专属 TRON 充值地址付款，系统确认充值后记入自有 USDT 复式账本，再由专业托管/MPC 服务自动归集至受保护配置指定的官方资金地址。

预期初始日资金总额低于 1,000 USDT。低规模不会降低幂等、账本、审批、对账、MPC 和灾难恢复要求。

## 决策

1. 生产钱包采用专业托管/MPC 服务；APP、业务 API、数据库和 Worker 均不得持有完整私钥、助记词或可单独完成签名的材料。
2. 只支持 TRON 主网上由受保护配置固定的官方 USDT-TRC20 合约。其他网络、TRX 及其他 TRC20 代币不入账。
3. 每个用户获得不可重分配的专属 TRON 充值地址。确认后的充值先记入 USDT 复式账本，自动归集是独立资金管理流程，不作为用户到账前置条件。
4. 官方归集地址只存在于生产 Secret Manager/受保护配置及托管策略中，不进入源码、客户端、普通日志或测试夹具。修改地址须双人审批、实时告警、提现熔断与全量对账。
5. USDT 与 CAIBI 保持两个独立账本，每个资产内部单独平衡；禁止跨资产分录平衡。兑换订单在一个数据库事务内关联一笔 USDT 账本交易和一笔 CAIBI 账本交易。
6. 固定兑换比例为 `1.00 USDT = 1.00 点钻`。兑换免手续费；链上提现手续费独立报价并明确展示。
7. USDT 为六位小数，点钻为两位小数。兑换最小金额及步长为 `0.01`；USDT 转点钻不得向上取整，不能兑换的六位小数余量留在用户 USDT 余额。
8. 点钻兑换 USDT 前必须验证平台可兑付 USDT 储备。储备不足、三方对账不平或链上/托管状态冲突时暂停反向兑换与提现。
9. 提现只允许发送官方 USDT-TRC20，且只接受通过服务端 TRON 主网 Base58Check 校验的目标地址。未知托管结果只能查询原订单，禁止创建第二笔出款。
10. 所有资金写入均要求幂等键、稳定原因码、操作者、追加审计记录和 Transactional Outbox。已过账错误只能通过关联冲正纠正。
11. Matrix 消息、Bot、推送、客户端状态、Webhook 和单一链上数据提供方均不是资金事实源。业务复式账本是用户余额事实源；链上、MPC 托管平台和内部账本执行三方对账。
12. 本决定不开放 USDT 用户间转账、USDT 红包、任意代币、任意网络、动态市场汇率或平台自建私钥签名系统。

## 安全与审批后果

- 兑换使点钻成为可兑付负债，必须持续证明受控 USDT 资产覆盖用户 USDT 负债、已承诺兑付及安全准备金。
- 账本模式、兑换公式、充值/归集/提现状态机、托管契约、确认阈值和破坏性 OpenAPI 变更均属于受保护变更。
- 实施前必须完成领域审查和 Quality/Security 审查；生产启用还必须完成对抗测试、三方对账、MPC 未知结果恢复、备份恢复和资金熔断演练。
- 法律、牌照、制裁、消费者保护和税务分析不在本技术 ADR 的结论范围内；在完成适用法律审查前不得据此直接面向真实用户开放资金功能。

## 被否决方案

### 所有用户直接向同一个地址充值

仅靠金额、时间或用户填写的交易哈希无法可靠归属交易，容易出现冒领、重复认领和客服人工改账，因此否决。

### APP 或业务服务器保存热钱包完整私钥

单点入侵即可转走全部资金，且难以实现独立审批和权限隔离，因此否决。

### 将点钻与 USDT 合并为一个账本资产

两种资产精度、用途和链上属性不同，合并会破坏资产内平衡、审计与储备证明，因此否决。

## 迁移与回退

- 使用 expand-migrate-contract：先新增兑换、冻结、链上事件、归集、提现和对账结构，再双写/验证，最后启用功能开关；不得破坏历史账本迁移。
- 默认关闭真实充值、反向兑换和提现。按“只读观察 → 受控充值 → 开放充值 → 单向兑换 → 反向兑换 → 邀请制提现 → 有限自动审批”分阶段启用。
- 回退只关闭入口并继续处理已广播交易、对账和结算；不得删除订单、回滚账本行或遗弃未知状态交易。
