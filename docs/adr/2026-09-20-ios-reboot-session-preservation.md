# ADR：iOS 重启会话恢复不得以暂不可访问作为删除依据

日期：2026-09-20。用户明确批准 `2026-09-20-ios-reboot-session` 方案并要求执行。
状态：设计已批准，规格符合性及质量/安全独立审查通过；本记录不代表iOS真机通过。

## 决定

沿用 ADR-0068 的“不确定时不清除”与 ADR-0063 的账号隔离约束。安装标记重新从存储读取，缺标记的iOS启动必须确认受保护数据可访问，目录成功枚举才可判定没有旧库。目录不存在、不可访问或类型错误都不能证明全新安装。真正新安装由path_provider创建支持目录，再进行枚举；不改变钥匙串accessibility或密钥内容。

已有安装标记时不要求解锁UI，保留既有首次解锁后锁屏来电启动路径；未注册或读取不到标记时以保留数据优先，延后到解锁重试。若初始化失败，销毁/避免遗留句柄，允许用户重试及前台返回重试。

只有业务会话已通过既有鉴权，才可恢复其对应Matrix账号。聊天本地状态暂不可用不代表业务会话失效，不自动撤销有效业务凭据；只有原有权威失效或显式退出路径可清除。恢复使用同一业务会话的聊天授权，不重做密码登录，不切换到其他账号。离线状态不申请聊天授权；身份不一致继续失败关闭。任何恢复迟到不得覆盖已退出状态。

密码登录前增加只读本地账号存储检查，已知本地损坏在远端替换设备前停止；仍然可能在预检成功后遇到目标库或网络错误，因此不承诺所有失败都不会触发既有单设备策略。

异常仅以固定类别与固定文案展示，保留内部阶段编号兼容性；不向UI传递原始异常、SQL、文件路径、账号、token或响应正文。

## 证据边界

已确认并用回归测试覆盖的是误清理判据、错误的会话撤销分支和缺乏真实重试/错误分类；尚未取得用户手机日志，不能认定本次所有历史不可见都是物理清库导致。Windows测试不能替代iOS16.7.16整机重启/锁屏来电/企业签名验证。未批准公开发布。
