# ADR-0006: 用户可见品牌与点钻资产名称

**状态：** 已批准
**日期：** 2026-08-23

## 决策

- 用户可见产品名为 **畅聊 ChatFlow**；主标题和应用标签使用全名，受空间限制的应用内文案可使用“畅聊”。账号标签为“畅聊号”。
- 用户可见 CAIBI 资产名称为 **点钻**，覆盖 Flutter、HTML、Figma、管理端、邮件、通知、红包与余额文案。
- `CAIBI` 继续作为唯一内部资产代码；既有表、迁移、账本事件、OpenAPI `asset` 值、Matrix 事件与历史数据不改名。
- 点钻继续采用两位小数；与六位小数 USDT 严格隔离，不引入兑换、USDT P2P 或 USDT 红包。

## 原因

名称替换必须覆盖所有用户界面，同时不能破坏不可变账本、API 客户端、历史迁移或事件兼容性。显示名称与内部代码分离允许品牌演进而不改变金融事实。

## 对外技术标识

本次迁移仅替换用户直接看到的移动端、HTML/Figma、邮件与管理端文案。OpenAPI 标题、健康检查 `service`、Docker 默认服务名与 TOTP issuer 保持现状，后续必须经过独立 API/运维兼容性审查才可更改。

## 后果

所有新的 UI 与内容必须从共享品牌常量/设计合同消费“畅聊 ChatFlow”和“点钻”。名称显示变更需要更新相关 UI、内容、Figma 账本、测试与可公开文档；内部 `CAIBI` 标识保留并受现有账本约束保护。
