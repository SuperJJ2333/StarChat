# ADR-0014：管理员钱包固定操作密码

日期：2026-09-08。状态：用户已明确选择管理员单独设置的固定操作密码；实现已通过领域及安全审阅，生产认证策略与界面已发布并通过健康、公开接口及静态文件校验，实际拥有者尚需自行设置凭证。

用户要求用独立固定操作密码替换管理后台人工 USDT 出款与安全操作的动态 MFA。适用范围仅为官方钱包拥有者管理员的后台敏感命令，不改变用户私人钱包控制权证明，也不接收官方钱包私钥或助记词。

固定操作密码与登录密码分离。它是可重复使用的知识凭证，不具有 TOTP 的到期或第二因素属性，不能继续标记为 MFA。密码采用项目现有密码哈希机制存储，明文不得进入日志、审计、Outbox、幂等记录或浏览器存储。保留近期登录、实际管理员身份和角色、失败限流、会话撤销检查、事务内凭证版本复验。更换操作密码使此前未完成授权失效。

初次设置要求当前登录密码和近期登录；修改要求当前登录密码及现有操作密码。新操作密码不得与登录密码相同。没有操作密码时敏感命令拒绝；禁止自动生成默认密码、把登录密码当作操作密码、从固定操作密码失败退回 TOTP 或默默删除旧 TOTP。忘记密码恢复流程需独立验证设计，不通过普通修改入口跳过旧凭证。

通过显式管理员认证策略配置切换。资金命令继续要求原幂等键、不可变交易摘要、实际操作者、审计、Outbox 和事务内校验。重复请求不得重复付款或重复落账。用户客户端原认证协议保持兼容；后台字段使用 operation_password，不把固定密码塞入名称为 mfa_proof 的协议字段。

本次变更不解除储备不足、监控交接、告警送达、资金暂停或链上核验阻断，不授予服务器签名能力。生产切换须在密码设置和所有相关路由接线测试、领域和安全审阅后进行。
