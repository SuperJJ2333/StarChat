# ADR-0063：切换账号保留本地聊天存储

2026-09-10；产品授权：本轮用户明确要求。领域评审：server_sessions_2084通过；Quality/Security评审：voice_2084通过。批准设计，实施仍须验收。

取代 ADR-0007 第4条中“确认切换账号即删除前账号数据库”的条件；明确清除本机聊天数据仍为独立显式操作。

采用 homeserver 精确地址与 MXID 的 SHA256 作为账号槽标识。旧单账号数据库、SQLCipher密钥、设备身份、Olm/Megolm、同步游标不搬移、不复制、不删除，注册为该账号的 legacy 槽。新账号使用独立数据库文件及系统安全存储key后缀，恢复原账号时重新选择原槽。安全存储保存槽注册表与原子当前槽指针；仅在旧客户端停止同步、资源与数据库句柄关闭后切换指针。注册表先写，指针后写，崩溃不会使旧数据丢失。未知/损坏注册表失败关闭，不生成替代密钥冒充旧库。

登录成功前关闭前账号访问能力；不存在两个当前在线客户端。旧库的访问必须经过对应账号业务认证；切换并不让未登录用户查看其他账号缓存。设备被顶后保留本地数据库，但过期Matrix凭据不能用于在线访问；同槽重新认证继续使用原deviceID和加密状态。缺失密钥不能由服务端伪造恢复，离线新增密文按标准同步和房间密钥备份能力恢复，不承诺没有任何可用密钥时可解密。

恢复密钥、数据库密钥、绑定、诊断盐和显式清库标记均按槽隔离。iOS现有受保护数据库密钥桥扩展严格的64位小写十六进制账号后缀，并显式允许当前槽指针及槽注册表两个固定元数据key，保证首次解锁后后台可选择同一数据库；保留AfterFirstUnlockThisDeviceOnly及非同步策略，其他秘密保持既有安全存储保护。不向服务器提交密钥、消息正文或附件明文。

清库只删除当前槽及其密钥，不影响其他账号。测试覆盖A→B→A、崩溃写失败、不同homeserver、并发选择/密钥操作、旧库原路径/密钥不变、槽间清理隔离、生命周期迟到回调与未登录访问拒绝。
