# ADR：畅聊号按365天冷却修改

日期2026-09-26；状态已批准，用户明确确认新改号6–20位方案。替代2026-08-12产品规格“用户名注册后不可修改”；继承ADR0085的绑定与恢复边界。

决定：业务User.username可修改，稳定业务UUID及Matrix ID不变。首次允许，之后UTC365天；新改号输入字母开头ASCII6–20、字母数字_/-，normalized大小写不敏感。注册/系统旧号兼容保留。当前账号必须ACTIVE，改号需认证、Idempotency-Key、事务行锁/唯一约束、审计/Outbox。availability受认证限频，最终写入再次校验。

新增旧号归属claims主键索引并回填现号和Matrix localpart。旧号永久归属原用户且不让他人复用；仅当前号允许登录/搜索。此措施必要，因为现开户从用户名派生Matrix localpart，释放旧号会使新注册命中已有Matrix身份。禁止修改已有Matrix ID/聊天密钥/房间，禁止服务端获得明文密钥。失败/重试同事务回滚；同normalized无变化不耗冷却。

迁移expand，不删除历史，不执行破坏性downgrade。手机号/邮箱/密码协议、财务与会话撤销策略不因改号变化。上线前需规格/领域与独立质量安全评审，PG并发/恢复/唯一索引及新号登录/搜索兼容证明。批准实现不以本ADR自动授予生产写权限。

2026-09-27用户独立批准发布API9083f027与worker15659d6c及0089迁移。兼容回退使用API1045b2b6与同一新worker：只移除三个新改号入口，保留claims-aware注册/手机号开户和共同锁序、新号归属、用户UUID/Matrix ID及0089数据。不得恢复原r4开户逻辑或删除claims；原r4不识别历史号归属，可能错误重用已有Matrix身份。
