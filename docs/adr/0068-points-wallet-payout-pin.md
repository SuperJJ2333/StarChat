# ADR-0068：点钻提现与用户支付密码

状态：用户已授权业务规则；领域（media）及 Quality/Security（profile）审阅通过，159项隔离财务用例通过；2026-09-11配套API已发布。真机交互/真实资金操作未代用户验收，见验证记录。
日期：2026-09-11。

用户确认本次钱包内提现以点钻为来源，按 1 点钻 = 1 USDT、零手续费、最低 10 USDT 提现到当前绑定 TRON 钱包。此授权延续 ADR-0010 的固定兑换及两资产独立账本；不产生 USDT P2P 或红包。

## 决策

- 充值仍是绑定地址向官方地址充值 USDT。提现报价增可选 funding_asset，历史缺省 USDT，新钱包使用 CAIBI；金额仍是六位 USDT 目标，CAIBI 须整分。报价固定金额、绑定版本、目标与来源资产，服务端不信任客户端收款地址。
- 请求通过已有支付密码授权服务新增 wallet.payout.create 用途，授权绑定 quote_id 与幂等键；quote_id 对应不可变完整报价。仅授权成功后，消费凭证、点钻兑换、USDT 冻结及订单/审计/Outbox 在同一事务完成；失败全部回滚。无凭证不得新建订单，require_all 兼容开关不豁免提现。
- 已受理订单按原幂等键恢复，无需再次扣款。未知结果保留原意图；PIN 与授权不落盘；账户和设备会话切换拒绝迟到提交。
- 取消未提交 CAIBI 订单，释放原 USDT 占用，并通过公共应用接口追加关联反向兑换分录退回原点钻，原订单/兑换记录保留。不得将取消解释为一次新兑换，不因储备证据过期阻塞原冻结释放；不得逆转 UNKNOWN 或已付款订单。
- 继续现有 conversion_enabled、人工付款流动性/储备策略、暂停、限额、绑定版本与30天改绑要求；不因页面重构扩大真实资金开关。
- 红包和转账支付业务保持；钱包直接复用同一支付密码设置、数字键盘、取消和错误 UI。

## 审阅与回退

领域审阅须核对金额精度、原子性、取消退回源资产、历史重放；随后质量安全审阅核对绕过PIN、错账号/会话、重试并发、秘密持久化。关闭新客户端入口可回退；不可删除历史订单/授权/审计或破坏性回退数据库。
