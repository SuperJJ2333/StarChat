# ADR-0083 客服后台常规会话访问

状态：用户2026-09-23明确要求批准；实施后需领域和质量/安全审查。

客服首次开通选择APP中已验证的邮箱或手机，验证码只发绑定目的地；既有已开通客服日常登录使用密码，不再要求图形或联系方式验证码。登录限频、密码验证、管理会话48小时/单设备撤销与禁用状态继续生效。不得借客服入口绕过管理员验证码；入口仅允许已开通客服角色。

客服充值和提现订单取消额外操作密码、TOTP及短期钱包grant，使用当前客服管理会话授权。在每次操作和金融提交之前仍实时验证账号、会话、客服开通与角色；业务认领、幂等、审批、到账证明、审计/Outbox保持。管理员专用钱包权限和二次验证不受影响，客服菜单隐藏专用USDT入口。该明确用户授权覆盖旧ADR/skill中支持订单必须二次验证的规则，范围不扩大到管理员钱包。

客服运营概览与管理员复用汇总指标/图表，只扩大汇总读取权限，不授予管理员写权限或个人数据明细。选择不同验证通道不能将已更换/撤销的绑定视为同一身份；保留历史开通兼容与变化后重新验证要求。

领域/规格审查与质量安全复审已完成，范围见验证记录2026-09-23-staff-console。混合管理员身份只能走管理员入口；邮箱选择同步覆盖实际worker发送前身份检查。
