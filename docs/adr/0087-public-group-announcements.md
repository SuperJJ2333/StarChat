# ADR-0087：群公告明文发布

> 2026-09-26 文档集成时由未提交草稿编号 0085 调整为 0087，避免与已提交的个人资料字符限制 ADR-0085 冲突；原 2026-09-24 授权及决策不变。

- 状态：用户已明确批准；2026-09-24，原话「今后公告不加密，旧公告由管理员重发」。
- 范围：仅群公告正文和新发布的公告图片。普通聊天正文、附件、恢复密钥与通话仍遵循端到端加密边界。
- 对应计划：[公告、钱包与客服](../superpowers/plans/2026-09-24-announcement-wallet-support.md)。

## 决策

保留 Matrix `com.changliao.group.announcement` state 的 `event_id` 引用。正文使用 `m.room.message` / `com.changliao.group.announcement.document`，经 Client.sendMessage 明文发布；图片使用 Client.uploadContent 上传原始字节，再发布带 `com.changliao.group.announcement.image: true` 标记的标准 `m.image` 事件。不得将此路径泛化为普通聊天的非加密发送开关。

公告受 Matrix 成员资格和 power levels 授权，群主/管理员才能发布和清空；发布前保护 state 权限，并在异步图片上传后、正文发送前、引用替换前重新校验成员及权限。引用发布失败时不假称成功。没有业务数据库公告副本，也不向业务 API 发送公告内容。

只读取当前 state 指向的同一发送者文档。兼容旧 topic 与有有效密钥的加密文档/图片。缺少旧密钥时显示管理员重新编写入口；不会自动清空或篡改历史。首次 SDK 读取可能使用其现有备份尝试，此后缓存失败事件，仅本地解密；移除公告显式 requestKey 循环。管理员明确发布时，本次保留且可读取的旧加密图片在设备解密后逐张重新上传为明文，文档引用新的图片事件；缺少旧图片密钥时阻止本次发布并提示删除或重新选择图片，原state引用保持不变。此操作仅涉及本次选择保留的图片，不批量迁移历史。

## 明确接受的保密性变化

本 ADR 是根 AGENTS、客户端 AGENTS 和产品规格「Matrix 不保存明文正文/附件」的用户授权局部例外。Matrix 服务器及媒体存储运营者能够读取新公告正文、图片和文件名；媒体链接遵循现有 Matrix 媒体访问规则，不承诺与房间权限等价的媒体保密性。UI 明示公告不加密。旧加密内容不会被后台批量解密或迁移，明文发布不能通过回退旧客户端撤销已公开内容。

## 验证与交付边界

红/绿、源码哈希、规格及质量安全审查记录位于 `docs/verification/artifacts/2026-09-24/announcement-public/`。此次子任务不构建、不部署、不发布；最终候选全量门禁由主任务执行。旧客户端可能拒绝显示新明文公告，升级后读取；双端真机接收与媒体网络访问仍需最终候选验收。
