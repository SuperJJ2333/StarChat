# ADR-0064: 管理后台钱包专用 60 分钟验证

日期：2026-09-10。产品决策由用户明确批准：钱包页面验证一次后固定有效 60 分钟，后台登录保持原时长；随后授权实施与生产部署。领域与质量/安全评审证据在本次 verification 记录中补齐后才上线。

## 决策

后台登录仍为原 48 小时。新增服务器持久化钱包授权，绑定当前管理员、设备、真实 admin session/family、验证方式、凭据版本及策略版本。仅授予原官方钱包管理员；不新增资金权限，不共享操作密码。固定截止时间为验证成功后 3600 秒，不因读取或刷新续期，也不越过后台登录有效期。

授权有效时钱包读接口和既有资金写入授权回调使用该授权，替代该范围内原 5 分钟近期登录与 30 秒单次证明。每次请求核实有效性；金融事务提交前复核截止时间，继续使用既有角色、冻结、幂等、对账、审计和 Outbox 约束。操作密码设置/变更保留显式凭据要求。密码/TOTP 不存浏览器缓存。

页面在验证前不加载敏感钱包数据。过期后隐藏并清除已渲染钱包内容，显示模态验证；关闭返回概览。账号范围内未确认请求保留，禁止自动重放。退出、会话替换、设备/会话撤销、角色撤销、验证方式或凭据版本变更使授权失效。

## 取舍与回滚

60 分钟内持有有效后台会话者可使用钱包授权，这是用户批准的便利性与操作验证频率调整；不声称仍等同原 30 秒操作证明。后台其他模块不改变。功能开关默认关闭；生产启用前完成备份、恢复演练、迁移和审查。关闭开关并回滚 API/静态资源恢复旧行为，新增授权表保留，不执行破坏性降级。原非 owner 只读角色尚无独立钱包验证策略，启用后钱包专用数据限现有 owner；需在发布说明明确这一限制。
