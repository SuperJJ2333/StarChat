# 钱包监控仅告警与未广播出款撤销

日期：2026-09-30。状态：用户已批准；实现、审查及服务端发布完成，原订单正式撤销和资金恢复待真实管理员操作。

## 决策与适用范围

1. 所有钱包**监控事故**继续持久化事故、审计、Outbox，并向已配置邮箱发送告警；人工储备监控、旧钱包监控、定时维护中的对账及孤儿订单扫描都不再调用全局提现暂停、安全限制或账本转出限制。人工发起的暂停和独立账户安全操作不在本决策范围。邮件失败继续重试并产生送达故障事故，不以此自动暂停资金。
2. 监控无权豁免任何资金操作自己的身份、余额、储备、链上最终性、覆盖、幂等、审批与提交时复核。无法取得必要证据的入账、出款执行或结算仍拒绝。既有暂停不会因部署或新事故自动解除，须经受控恢复命令处理。
3. 已开始人工执行的出款不可复用 `CANCELLED`：其数据库约束要求从未领取。新增终态 `VOIDED`，用户界面显示“已撤销（确认未广播）”，保留领取者、领取时间、原指令、汇率调整、事故及完整审计。`SETTLED`、已有 `CANCELLED`、有候选交易哈希或已分配链上付款事件的订单不能进入 `VOIDED`。
4. `VOIDED` 只由有钱包写入权限的官方钱包管理员，通过近期身份验证、独立操作验证、明确“从未签名、从未广播”声明、原因码和幂等键发起。服务端核对原订单、签名钱包声明、链上观察器的新鲜覆盖及该笔目标、金额、时间范围内的转出记录。来源不可用、扫描落后、存在疑似转出或并发状态变化时拒绝；单源未发现转出不被表述为数学上的未广播证明。声明承担剩余的迟到广播风险。
5. 在同一金融事务内锁定预算、原订单与关联兑换，冲回最终应付金额的 USDT HOLD；如果订单由 CAIBI 兑换而来，按原兑换精确冲回完整 USDT 和 CAIBI 分录。调整汇率已退给用户的差额计入可用 USDT，必须足额才能完成整笔冲回；余额不足则原子拒绝，不制造负余额或部分撤销。补偿仅可在该 `VOIDED` 命令中通过严格校验的账本接口执行，不形成通用限制豁免。出款待处理计数同步归零，并写审计与 Outbox。
6. 当前生产事故 `75c01afc-29e7-416f-9609-581973994b14` 与订单 `3e728fe3-7343-4036-b9a0-646e56a46457` 只在新命令上线、管理员完成生产声明及服务端复核后处理。随后单独复核事故、经现有授权恢复命令解除原有暂停。不得通过 SQL 改订单、余额、限制或事故状态。

## 依据与风险

2026-09-29 的生产只读核对：订单为 `UNKNOWN`，无候选 txid、无已分配出款事件；客服已开始付款，最终应付 10.000000 USDT。官方观察库自领取时间后未发现转出且最近状态为 `SOURCE_MATCHED`，但其为 TronGrid 单源，只能提供有界观察。用户于本会话确认该单从未签名、从未广播，并批准上述后台再次声明与复核流程。邮件告警已有发布和投递回执。

本决策替代 ADR-0013 中“所有人工监控危险信号自动暂停”和“已领取出款绝不解冻”的一般规则，仅在上述受控 `VOIDED` 命令与监控动作范围内例外；其余人工签名、链上结算和不可重复付款规则保持。全局自动暂停移除后，事故期间某些与异常无直接证据依赖的交易可能继续发生，这是用户明确选择的运行风险。若发现账本完整性或实际储备异常，相关写入仍由各自证据门槛拒绝；不能把邮件投递成功当作资金安全证明。

## 验收与回退

先以失败测试覆盖监控全代码路径不写三项全局限制、事故邮件与审计照常、现有暂停不自动释放，以及无证据资金操作拒绝。再覆盖 `UNKNOWN → VOIDED` 的权限、声明、无候选、扫描新鲜度、异常转出、汇率调整、余额不足、并发、幂等、账本平衡、审计/Outbox 与回退。完成领域审查和质量/安全审查后才部署。迁移仅扩展允许的终态及必要证据列，旧镜像不可用于读取 `VOIDED`；回退使用兼容新终态的镜像，保留事故、命令与账本历史，不做破坏性降迁移。

## 客户端兼容补充

用户只读订单接口对旧客户端投影 `status=CANCELLED`，并以新增 `terminal_status=VOIDED` 保留精确终态；新版客户端识别该组合，展示“已撤销（确认未广播）”。旧客户端显示已有的取消文案，并只能开始另一个新订单，不能继续处理原单。数据库、领域服务、后台、审计、幂等及通用钱包历史仍为 `VOIDED`；此投影不执行 `UNKNOWN → CANCELLED` 数据库转换。领域审查确认该兼容投影不增加金融状态转换。
