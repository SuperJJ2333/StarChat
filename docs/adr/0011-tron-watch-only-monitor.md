# ADR-0011：独立TRON只读监控

**状态：** 用户2026-09-07授权只读监控及隔离验证；领域与Quality/Security源码审阅通过。

## 决策

新增独立观察进程，从TRON主网只读接口发现官方USDT转账及固化余额；持久化到与业务数据库隔离的观察存储。真实地址由受限部署配置注入。进程无私钥、无签名权限、无金融写入接口。

只读数据源可采用TronGrid，标记为单来源观察。SOURCE_MATCHED仅表示本来源稳定截点间余额差与观察净流量一致，不满足ADR-0010双来源最终性、受控资产证明或用户资金记账条件。索引水位和进程健康不得解释为完整链历史和金融服务就绪。

不改变ADR-0010的生产资金关闭门禁、地址分配、托管工厂或金融状态机。本次没有实现自管签名来替代现有托管合同。自管签名、专属地址池及真实资金开放须在后续独立ADR/实施及相应基础设施验收中完成；用户已明确尚未准备签名设备，先完成本ADR范围。

## 后果

可以观察真实地址、回补明确范围内的历史、留存未匹配转出及扫描错误，而不接触业务余额。单机观察数据库可重扫重建，不提供金融RPO=0承诺。外部通知未配置时明确报告不可用，不把本地异常记录称为告警送达。

规格与验证分别见2026-09-07-self-managed-tron-wallet设计、2026-09-07-tron-watch-only验证记录。
