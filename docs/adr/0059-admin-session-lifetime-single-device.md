# ADR-0059：管理后台 48 小时独立单设备会话

状态：用户于 2026-09-08 随设计一并批准；领域与质量/安全独立审查已通过，证据见 docs/verification/2026-09-08-admin-console-modernization.md。

日期：2026-09-08。

## 决策背景

用户要求管理后台登录保留 48 小时，并已明确选择新设备登录成功后旧设备立即失效。目前管理登录复用普通用户令牌服务，前端仅保存短期访问令牌，设备标识固定，不能满足要求。

## 决策

引入独立管理会话边界。服务端维护绝对到期时间（登录起 48 小时），短期访问令牌通过专用 HttpOnly 刷新 Cookie 续期；续期不能延长绝对期限。同一管理员成功新登录在事务中撤销原管理会话，访问与刷新均验证会话有效性，并保证并发下只保留一个有效管理会话。通用用户令牌不得绕过管理会话检查。

保留近期认证、操作密码、RBAC、验证码、审计、限流及刷新重放防护。近期认证仅更新敏感操作验证时刻，不创建超过原期限的会话；退出、替换和过期分别记录稳定原因码。任何日志不得含密码、令牌或 Cookie。

普通用户及 Matrix 会话不属于本限制。部署时已有浏览器管理会话需要重新登录一次；数据库采用可兼容的新增结构，回退不得重新激活已撤销会话。

## 备选方案

- 将访问 JWT 直接延长至 48 小时：无法单独保证撤销和安全续期，不采用。
- 只在浏览器保存到期时间：可绕过，也无法可靠处理并发设备，不采用。

## 验证要求

到期边界、并发新登录、旧访问/刷新即时拒绝、跨用户与普通会话隔离、多标签续期、CSRF、操作近期认证、迁移兼容与回退的专项证据齐全后发布。详细界面与统计设计见 `docs/superpowers/specs/2026-09-08-admin-console-modernization-design.md`。
