# 管理后台会话与报表运行说明

对应设计：2026-09-08 admin-console-modernization；ADR-0059 已获用户批准。

## 管理员使用

- 登录起固定 48 小时有效。关闭浏览器后再次打开可通过受保护 Cookie 恢复；访问令牌最多 15 分钟，由前端自动续期，不延长 48 小时截止时间。
- 同一管理员的新登录立即撤销旧管理会话。旧设备的请求立即拒绝；在线页面每 30 秒及重新进入前台时检查状态。
- 普通用户和 Matrix 移动端会话不受单设备管理策略影响。同浏览器多标签通过 Web Locks 串行续期，已打开页面绑定账号和会话 ID。
- 敏感操作出现近期认证要求时，输入登录密码完成验证，然后核对表单并手动再次提交。原表单保留；系统不会重放资金写请求。
- 新设备登录、到期、主动退出、刷新令牌重用分别通过服务端会话状态处理。排查时只记录原因码、时间、脱敏主体及 trace_id，禁止记录令牌、Cookie 和密码。

## 钱包及报表

- “暂停”状态仅显示恢复操作及未结事故等阻断条件；恢复继续要求服务端证据、控制版本、操作密码和原有全部安全检查。
- 右上角蓝色刷新按钮刷新当前页可见数据。出款、事故、资金启停和安全设置保留草稿、选中记录及分页；失败保留上次数据并显示过期提示。
- 注册趋势按 UTC+8 自然日统计（页面标注北京时间），范围 7/30/90 天，今天为尚未结束的一天。零值表示真实没有注册，请求失败不展示虚假的零值。
- 平台点钻总量为 CAIBI 清算账户净额取反，包含用户、冻结、托管及平台手续费持有。累计发行/回收按每笔交易的清算账户净变化计算；转账、红包流转不重复算作发行。
- 运营概览默认展示发行与回收记录；点击“查看凭证”打开可滚动弹窗，查看原交易、冲正与审计凭证。账本一致性或关联异常只提示核查，不自动修补账本。平台总量不等同于用户可兑付负债或 USDT 储备。

## 发布顺序

1. 记录现有应用镜像标识、迁移版本、反向代理规则和回退配置，备份业务数据库并按现有恢复流程确认备份可用；不导出运行凭证到仓库。
2. 在正式环境使用现有部署的数据库连接执行 `alembic upgrade head`。新增迁移 `0055_admin_sessions` 在 `identity_admin_sessions` 保存当前管理会话及截止/近期认证时间，不重写历史账本。
3. 新 API、静态管理页面及 OpenAPI 合约作为同一兼容版本发布。保持 HTTPS、反向代理原始 Host 和 `/api/v1/auth/admin-session` Cookie 路径，不缓存认证响应。Cookie 为 Secure、HttpOnly、SameSite=Strict。
4. 已登录管理浏览器需要重新登录一次。检查验证码登录、关闭/重开、续期、第二设备替换、退出、近期认证、钱包状态、趋势与点钻凭证。检查普通移动端会话仍有效。
5. 验证发布前后资金状态一致；部署本身不解除钱包暂停、不触发发放、不处理或重放出款。

## 回退约束

- 0055 为扩展迁移，降级删除管理会话表被明确禁止。保留新增表和所有已撤销 refresh family，不能通过回退重新激活旧会话。
- 旧应用缺少管理会话边界，直接切回旧镜像会重新允许普通令牌进入管理接口。因此安全回退必须保留新版认证边界，或暂时关闭后台入口及全部旧管理写接口，再替换为修复镜像。
- 不回滚账本、资金状态、审计、Outbox 或已有钱包日志系统。
- 本次验证在本地隔离 PostgreSQL 执行了并发登录/刷新及迁移链测试；未在生产主动演练回退。

## 2026-09-10 后台可读性更新

- 管理台、登录页和标签页使用移动端提供的原始 LOGO。拖动侧栏右侧边缘调整宽度（200–360px）；边缘箭头收起/展开。聚焦拖动条后，左右方向键调宽，Home/End 调到边界；窄屏使用抽屉。
- 所有绝对时间以北京时间 `yyyy-mm-dd hh:mm:ss` 展示；链上查询的时间输入也按北京时间解释。注册趋势属于自然日汇总，保留日期而不虚构时分秒。
- 注册明细的列为注册时间、畅聊号、用户名、邮箱验证、账号状态。畅聊号来自 `username`，用户名展示昵称 `nickname`；原“主渠道/验证率”是与用户明细数据不匹配的旧表头，已移除。
- 用户列表可按畅聊号、昵称或邮箱搜索，并使用服务端游标翻页；不向页面返回完整邮箱。搜索或分页失败保留上次成功列表和页码，可重新加载失败请求。
- 封禁表单置顶：从列表选择用户，或切换 IP 输入地址；中文原因菜单和 1 小时/24 小时/7 天/30 天/永久时长菜单。宽屏控件同排，手机依屏宽排列。点击选择用户不会执行封禁，只有“确认封禁”提交；结果不明确时不自动重放。
- 凭证操作人优先显示畅聊号，系统操作和无法关联账号有明确占位；历史 actor_id 与审计数据不重写。业务原因使用中文映射，未知历史原因显示待补充说明。
- 本更新增加只读查询字段和筛选参数，未增加迁移或改变资金规则。发布时需配套新 API 和静态页面；本轮只完成本地实现与验收，尚未执行生产发布。Figma 同步经用户明确批准暂缓。
