# 钱包日结与事故处置（Sandbox）

本轮接口接入业务 API 与 Worker；真实资金和生产处置写入继续关闭。此流程不发送真实短信、邮件或第三方消息。`SANDBOX` 回执仅表示本地耐久接收，不能解释为值班人员已收到告警。

## 日常流水与封存

- `GET /api/v1/admin/wallet/reports/daily?day=YYYY-MM-DD&format=json|csv` 查看香港日期的流水预览。
- `POST /api/v1/admin/wallet/reports/close`，请求体 `{"day":"2026-09-05","reason_code":"DAILY_CLOSE"}`，请求头附 `Idempotency-Key`，封存过去日期。
- `GET /api/v1/admin/wallet/reports/closed/{id}` 读取原始快照并核验摘要。

日结包含所有捕获分录、期初、增减、期末及逐笔资产平衡证据。相同键、相同操作者和参数重试返回原结果；冲突拒绝。后补分录只能通过新键产生新版本，`previous_id` 指向前一版本，旧快照保留。`cutoff_kind=CAPTURED_ENTRY_SET` 表示实际捕获分录集；内层 `finalized=false` 不会伪装为禁止补录的全局会计期间。哈希与数据库保存不等于独立 WORM 存证。在线证据超过 100,000 条时拒绝截断导出，需要另行设计离线大账本通道。

## 监控与处置

Worker 每 30 秒独立运行钱包监控。检查账本证据、储备覆盖、外部孤儿订单、超过五分钟的未知/提交中提现、全局暂停以及失败或延迟的告警队列。发现异常调用现有钱包暂停接口，不改写账本、不释放提现冻结。读取失败保持此前异常，记录 `MONITOR_UNAVAILABLE`；损坏账本证据为 P0。完整扫描之间互斥，忙碌扫描不伪造成功心跳。

1. 财务角色调用 `GET /api/v1/admin/wallet/incidents?limit=50`，使用 `next_cursor` 分页；`GET /incidents/{id}` 获取版本和条件状态。
2. 调用 `POST /incidents/{id}/ack`，提交 `expected_version`、`reason_code` 和幂等键，登记处理人。P0 未确认超过五分钟进入持久化升级，同一五分钟区间最多一次。
3. 调查原始订单和账本证据，修复原因。未知出款先查询原订单；不得用新订单重付。结案动作不会撤销链上交易。
4. 完整扫描确认原条件消失后，服务端生成 `clearance_digest`，读取最新版本。另一位财务人员调用 `POST /incidents/{id}/resolve`，提交最新版本、服务端摘要、原因码和新幂等键。
5. 新结案会再次扫描；扫描失败拒绝结案，版本变化要求重新核对。成功命令的同参数重试直接返回耐久结果。再次出现的异常会重新打开并清除旧确认和旧复核。

结案不等于钱包解冻，也不释放任何资金。恢复交易必须执行既有资金复核流程。所有新操作要求真实登录会话在五分钟内创建，刷新令牌不能延长此时限。这是 Sandbox 最近登录限制，不是 TOTP；生产环境返回 503，待真实操作 MFA 和告警设施集成后才能另行开放。

## 健康、投递与故障

`GET /api/v1/admin/wallet/monitor/status` 返回最后尝试、最后完整扫描和 `stale`。未启动或超过 120 秒无完整扫描即过期。必须用独立于 Worker 的基础设施监控轮询状态及数据库/进程健康；Worker 整体停止时不能自行发送告警。

`wallet.alert` 使用现有 Outbox：失败指数退避，最多十次后保留为 DEAD；处理完成但确认丢失时，租约过期后重领。`wallet_alert_receipts.event_id` 唯一，重领不产生第二条回执。其他业务审计事件不代表告警投递。生产不注册 Sandbox 消费器。

PostgreSQL 采用独立会话级扫描锁，适用于多个 API/Worker 进程。SQLite 文件数据库使用相邻操作锁文件；内存数据库仅供单进程测试。进程终止释放操作系统/数据库会话锁，锁文件存在本身不代表锁仍被占用。

## 迁移与回退

0041 仅增加五张运行表，保留金融分录。发布顺序应先完成迁移验证再启用新版业务进程；停止新操作及回退应用时保留这些表、Outbox 和快照，禁止删除封存证据。降级脚本主动拒绝破坏性删表。

隔离 PostgreSQL 已验证新 DDL 保留旧数据；完整历史迁移链仍有 0025 重复添加 `moments_preferences.cover_url` 的已知阻塞，不能据此直接在生产升级。本轮未部署或运行生产迁移。真实 MPC、独立链证明、跨故障域 RPO=0、灾备、外部通知 SLA 与 iOS 真机验收仍须分别完成。
