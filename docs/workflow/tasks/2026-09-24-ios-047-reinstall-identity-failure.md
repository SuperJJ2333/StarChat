## 交接与回退

- 已确认：故障发生在用户未主动登录的启动阶段；页面形态与本地会话自动恢复的失败页一致。Keychain 残留可能存在，但不是已确认根因；`-34018` 钥匙串权限错误会显示另一文案。回签 2172 含新增强制加载动态库，因果未确认。
- 后续独立证据：用户确认 **2144 旧账号 L07 早于 2172 安装**；同机新账号可登录。2144 20:19:57 +08 真机安全事件证实旧账号的保存绑定与实际 Olm Ed25519 指纹不一致，详见[2144 独立诊断](2026-09-24-ios2144-old-account-l07.md)。这排除了 2172 新增动态库作为旧版 L07 的必要原因，但 **2172 的启动错误尚未取得事件码**，不得据此直接认定两版同根。
- 待办：优先让签名方从原始候选输出不注入动态库、App ID 与 Bundle ID 相符的纯重签 IPA，在设备上直接覆盖对照；如仍失败，取得脱敏本地 `E2EE_*` 事件码/阶段。iOS 16.7.16、19:21 HKT、真“删除 App”已获用户确认。
- 已发布/候选：候选源码与用户回签包有对应构建记录，真机二进制运行路径尚无日志；生产 iOS 2172 已停发，旧 2144 恢复，Android 不变。
