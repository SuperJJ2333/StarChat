# 任务记录模板

## 恢复入口

- 目标、用户授权来源及边界：
- 关联计划/ADR：
- 当前状态：调查 / 实现 / 验证 / 构建 / 待签名 / 发布 / 待真机 / 完成
- 负责人、工作树、文件所有权、源码commit：
- 最后更新时间（含时区）：
- 下一条具体操作、必要输入、阻断的验收ID：
